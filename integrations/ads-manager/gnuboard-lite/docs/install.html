솔애드 라이트 설치 가이드

그누보드5 게시판의 동영상을 Video.js 플레이어로 바꾸고, 재생 전에 광고 영상 1개(프리롤)를 보여 주는 플러그인이에요. 코어 파일은 고치지 않고, FTP와 브라우저만으로 설치할 수 있어요.

1. 구성 파일

서버에 올리는 것은 upload 폴더 안의 파일뿐이에요.

solad-lite-gnuboard-{{VERSION}}/
├─ README.txt                 빠른 설치 요약
├─ docs/                      이 설치 가이드와 게시판 연동 가이드
└─ upload/                    그누보드 루트에 그대로 올리는 파일
    ├─ extend/solad_lite.extend.php       관리자 메뉴 추가, 페이지에 플레이어 스크립트 넣기
    ├─ adm/solad_lite_form.php            광고 설정 화면
    ├─ adm/solad_lite_form_update.php     광고 설정 저장
    └─ plugin/solad_lite/
        ├─ solad_lite.lib.php             설정, 광고 편성, PHP 함수
        ├─ solad-lite.js / solad-lite.css 플레이어 스크립트와 스타일
        ├─ vendor/                        Video.js 플레이어와 광고 모듈(ads.js)
        ├─ example.php                    예제 페이지(최고관리자만)
        └─ sample/                        예제 영상, 시험용 광고 영상

들어 있는 기능은 플레이어 교체와 프리롤 광고 1개뿐이에요. 광고 여러 개, 미드롤·포스트롤, 노출 통계, 광고주 관리는 솔애드 정식판 기능이에요.

2. 필요 환경

  • 그누보드 5.6 이상 (5.6.43에서 확인)
  • PHP 7.4 이상
  • 최신 브라우저(크롬·엣지·사파리·파이어폭스). 플레이어는 자바스크립트 모듈로 동작해요.

ffmpeg, Composer, Node.js, 따로 하는 DB 작업은 필요 없어요. 설정 테이블(g5_solad_lite)은 광고 설정 화면을 처음 열 때 자동으로 만들어져요.

3. 파일 올리기

  1. 압축을 풀고 upload 폴더를 열어요.
  2. 안에 있는 extend, adm, plugin 폴더를 그누보드 루트(common.php가 있는 곳)에 그대로 올려요. 같은 이름의 폴더와 합쳐지면 돼요.
  3. data 폴더에 쓰기 권한(707)이 있는지 확인해요. 그누보드가 정상 동작 중이면 이미 되어 있어요. 광고 영상은 data/solad_lite에 저장돼요.
FTP로 올릴 때는 바이너리 모드로 올려 주세요. 텍스트 모드로 올리면 vendor 안의 파일이나 예제 영상이 깨질 수 있어요.

4. 광고 설정

  1. 최고관리자로 로그인하고 관리자 > 게시판관리 > 솔애드 라이트 광고를 열어요.
  2. 플레이어 사용이 켜져 있는지 확인해요. 켜져 있으면 게시판 글의 동영상이 플레이어로 바뀌어요.
  3. 광고 영상에 mp4 또는 webm 파일을 올려요. 시험할 때는 plugin/solad_lite/sample/sample-ad.mp4를 써도 돼요.
  4. 필요하면 광고 링크(광고를 누르면 새 창으로 열 주소)와 광고 설명(화면 읽기 프로그램이 읽는 문구)을 적어요.
  5. 광고 사용을 켜고 확인을 눌러요. "지금 광고가 나가고 있습니다."가 보이면 끝이에요.

광고는 프리롤(본편 앞) 1개로 고정이고, 광고가 시작되고 5초가 지나면 [광고 건너뛰기]를 누를 수 있어요. 건너뛰지 않으면 광고가 끝까지 나온 뒤 본편이 이어서 재생돼요.

  • 올릴 수 있는 파일은 .mp4와 .webm뿐이에요. 확장자만 바꾼 파일은 파일 앞부분을 검사해서 거절해요.
  • 새 광고 영상을 올리면 이전 광고 영상 파일은 지워져요.
  • 광고를 잠시 멈추려면 광고 사용만 끄면 돼요. 플레이어는 그대로 남아요.
  • 광고 영상은 가로 16:9, 30초 이하, 5MB 안팎을 권장해요. 모바일에서는 광고가 길고 무거울수록 이탈이 늘어요.

5. 적용 게시판

적용 게시판에서 아무것도 고르지 않으면 모든 게시판에 적용돼요. 일부 게시판에만 쓰려면 그 게시판만 체크하세요.

적용된 게시판의 글 보기 화면에서는

  • 첨부한 mp4·webm 파일이 본문 위에 플레이어로 나오고,
  • 본문 안에 들어간 <video> 태그도 그 자리에서 플레이어로 바뀌어요.

기존 글도 그대로 적용돼요. 게시판 스킨을 고칠 필요는 없어요. 스킨이 달라 본문 영역을 못 찾는 경우와, 게시판이 아닌 페이지에 플레이어를 넣는 방법은 게시판 연동 가이드를 보세요.

6. 업로드 용량

동영상은 용량이 커서 기본 설정으로는 올라가지 않을 수 있어요. 두 곳을 확인하세요.

  1. 게시판 설정: 관리자 > 게시판관리 > 해당 게시판 수정 > 파일 업로드 용량을 늘려요(예: 52428800 = 50MB).
  2. PHP 설정: upload_max_filesize와 post_max_size가 올릴 파일보다 커야 해요. 광고 설정 화면의 광고 영상 칸에 지금 서버 한도가 보여요. 호스팅 관리 화면이나 .user.ini에서 바꿀 수 있어요. 
; .user.ini (그누보드 루트, 호스팅이 허용하는 경우)
upload_max_filesize = 64M
post_max_size = 64M

7. 설치 확인

  1. 최고관리자로 https://내사이트/plugin/solad_lite/example.php를 열어요. 예제 플레이어 3개가 보이면 플레이어 파일이 제대로 올라간 거예요.
  2. 적용 게시판에 mp4 파일을 첨부한 글을 하나 써요.
  3. 글을 열고 재생하면 광고가 먼저 나오고, 오른쪽 아래 버튼이 "5초 후 건너뛰기"부터 줄어들다 "광고 건너뛰기"로 바뀌어요.
  4. 건너뛰기를 누르거나 광고가 끝나면 본편이 재생돼요.

광고는 플레이어마다 처음 재생할 때 한 번 나와요. 다시 확인하려면 페이지를 새로 고치세요.

8. 운영자 권한

최고관리자가 아닌 운영자에게 광고 설정을 맡기려면 관리자 > 환경설정 > 관리권한설정에서 그 회원에게 솔애드 라이트 광고(메뉴 코드 300960) 권한을 주세요. 읽기(r)는 보기, 쓰기(w)는 저장이에요.

다른 플러그인과 메뉴 코드가 겹치면 설정 파일에서 SOLAD_LITE_MENU를 바꿀 수 있어요.

9. 업데이트·삭제

업데이트

새 버전의 upload 폴더를 같은 자리에 덮어 올리세요. 설정(DB)과 올린 광고 영상(data/solad_lite)은 그대로 남아요. 직접 만든 extend/solad_lite.config.php도 패키지에 없어서 덮어쓰이지 않아요.

삭제

  1. extend/solad_lite.extend.php를 지우면 플레이어와 메뉴가 바로 꺼져요.
  2. 완전히 지우려면 adm/solad_lite_form.php, adm/solad_lite_form_update.php, plugin/solad_lite/, data/solad_lite/를 지우고 DB에서 g5_solad_lite 테이블을 지워요.

10. 문제 해결

관리자 메뉴에 "솔애드 라이트 광고"가 없어요.
extend/solad_lite.extend.php가 그누보드 루트의 extend 폴더에 있는지 확인하세요. upload/extend처럼 한 단계 더 들어가 있으면 읽히지 않아요.
"광고 영상이 서버 업로드 한도보다 큽니다."가 나와요.
업로드 용량의 PHP 설정을 늘리거나, 광고 영상을 더 작게 인코딩하세요.
저장하면 "요청 한도(post_max_size)보다 큽니다."가 나와요.
올린 파일이 PHP post_max_size보다 커서 서버가 요청을 통째로 버린 거예요. PHP 한도를 늘리거나 파일을 줄이세요.
저장하면 "올바른 방법으로 이용해 주십시오."가 나와요.
관리자 보안 토큰이 맞지 않는 경우예요. 화면을 새로 고친 뒤 다시 저장하세요. 브라우저 확장 프로그램이 관리자 스크립트를 막고 있지 않은지도 확인하세요.
글 보기 화면에 플레이어가 안 나오고 첨부 파일 목록만 보여요.
  • 광고 설정의 플레이어 사용이 켜져 있는지, 적용 게시판에 그 게시판이 들어 있는지(아무것도 고르지 않으면 전체) 확인하세요.
  • 첨부 파일 확장자가 mp4·webm인지 확인하세요. mov, avi 등은 바꾸지 않아요.
  • 브라우저 개발자 도구(F12) 콘솔에 "본문 영역(#bo_v_con)을 찾지 못해"가 보이면 스킨의 본문 영역이 다른 거예요. 본문 영역 바꾸기를 보세요.
플레이어 틀만 보이고 재생이 안 돼요.
  • F12 > 네트워크에서 plugin/solad_lite/vendor/ 파일이 404면 vendor 폴더가 덜 올라간 거예요. 다시 올리세요.
  • mp4가 H.264(영상)·AAC(음성)인지 확인하세요. H.265(HEVC)는 브라우저에 따라 재생되지 않아요.
광고가 안 나와요.
광고 설정 화면에 "지금 광고가 나가고 있습니다."가 보이는지 확인하세요. 보이는데도 안 나오면 data/solad_lite/schedule.json이 열리는지 브라우저로 확인하세요. nginx 등에서 data 폴더의 json 접근을 막았다면 풀어 주세요.
