설명서

플레이어를 사이트에 설치하고, 프리셋과 지면 편성을 운영하는 순서예요. 옵션 하나하나는 도움말에 있어요.

이 매니저가 하는 일

#‘이 매니저가 하는 일’ 절 주소

사이트 운영자가 자기 서버에 설치해서 영상 광고를 운영하는 관리자예요. 중앙 서비스나 결제는 없고, 데이터와 광고 파일은 설치한 서버에만 있어요.

  • 광고 소재를 올리고 영상·게시판·분류·사이트 단위로 광고 편성을 게시해요.
  • 플레이어 모습(테마, 재생 동작, 표시, 언어, 광고 화면)을 프리셋으로 정해요.
  • 사이트에는 자리 요소와 로더 한 줄만 붙이고, 모습은 사이트 적용 프리셋을 따라요.
  • 광고 시작, 완료, 건너뛰기, 클릭을 모아 통계와 CSV로 보여 줘요.

설치 순서

#‘설치 순서’ 절 주소
  1. 관리자를 영상 페이지와 같은 사이트에 설치해요. 웹 서버의 문서 루트를 관리자의 public/으로 두거나, 사이트 아래 /ads/처럼 경로를 나눠 설치해요. 플레이어 파일(public/assets/)도 함께 있어야 해요.
  2. 사이트에 적용할 프리셋을 골라요. 관리자 플레이어 메뉴의 프리셋 목록에서 "사이트에 적용"을 눌러요. 고르지 않으면 내장 "기본" 프리셋으로 나와요.
  3. 영상을 넣을 자리에 설치 코드를 붙여요. 관리자 플레이어 메뉴의 설치 코드 화면이나 데모에서 복사하고, data-video-id와 data-src를 영상에 맞게 바꿔요. 영상 ID는 지면 편성의 영상 ID와 같아야 광고가 붙어요.
  4. 페이지를 새로고침해서 확인해요. 이 코드로 재생하면 실제 통계에 기록돼요. 기록 없이 확인하려면 데모나 지면 편성의 미리보기를 써 주세요.
설치 코드 예 
<div data-solad-player data-video-id="intro-2026" data-src="/media/intro.mp4"></div>
<script type="module" src="/ads/player/loader.js"></script>

프리셋 만들기 · 복제 · 사이트 적용

#‘프리셋 만들기 · 복제 · 사이트 적용’ 절 주소

프리셋은 플레이어 설정 묶음이에요. 관리자 플레이어 메뉴에서 만들고, 편집기 옆 미리보기로 저장하기 전 모습을 볼 수 있어요. 미리보기는 통계에 남지 않아요.

  • 내장 프리셋은 기본, 플랫, 둥근 테두리, 강조색, 강의 다섯 가지예요. 바꾸거나 지울 수 없고, 복제하거나 사이트에 적용할 수 있어요.
  • 저장 프리셋은 20개까지 만들 수 있어요. 처음 고른 플레이어 종류(Video.js, 기본 video)는 바꿀 수 없어요.
  • "사이트에 적용"한 프리셋 하나를 data-preset이 없는 모든 자리 요소가 써요. 사이트 적용 프리셋을 지우면 내장 "기본"으로 돌아가요.
  • 저장하면 이전 값은 남지 않아요. 바꾸기 전 값을 지키려면 먼저 복제해 두세요. 변경 이력과 되돌리기는 준비 중이에요.
  • 일부 값은 저장만 되고 아직 화면에 쓰이지 않아요. 도움말의 프리셋 설정 옵션에서 적용 단계를 볼 수 있어요.

지면 편성과 게시

#‘지면 편성과 게시’ 절 주소

지면 편성은 어느 영상에 어떤 광고를 어디(프리롤, 미드롤, 포스트롤)에 넣을지 정해요. 초안을 저장한 뒤 게시해야 방문자에게 나와요.

  1. 소재(그누보드에서는 하우스 광고) 메뉴에서 광고 파일을 올려요.
  2. 지면 편성에서 대상을 고르고 광고를 넣은 뒤 초안을 저장해요.
  3. 게시 전 미리보기로 확인해요. 고른 프리셋 모양으로 재생하고 통계에 남기지 않아요.
  4. 저장한 초안을 게시해요. 게시본은 바뀌지 않고, 다시 고치면 새 게시본이 생겨요.

한 영상에 맞는 편성은 영상, 게시판 안의 분류, 게시판, 사이트 순서로 찾아요. 위 단계에서 편성 전체를 바꾸거나 광고를 끄거나 아래 단계를 그대로 따르게 할 수 있어요.

재생 테스트로 확인하기

#‘재생 테스트로 확인하기’ 절 주소

재생 테스트 페이지는 게시한 편성을 실제 서비스와 같은 방법으로 재생해요. 여기서 재생한 시작·완료·클릭은 통계에 쌓여요.

  • 관리자 지면 편성의 "Video.js로 재생", "기본 video로 재생" 링크로 열어요. 주소의 video 값이 재생할 영상 ID예요.
  • 페이지 위의 전환 링크로 플레이어, 미디어(MP4·HLS), HLS 엔진을 바꿀 수 있어요. 나머지 주소 값은 그대로 남아요.
  • 통계를 남기지 않고 보려면 데모나 지면 편성의 게시 전 미리보기를 써 주세요.

데모 샘플 준비하기

#‘데모 샘플 준비하기’ 항목 주소

데모와 관리자의 플레이어 미리보기는 Grok 샘플을 재생해요. 샘플은 저장소에 들어 있지 않아서 서버에 직접 넣어야 해요. 없으면 대신할 영상을 만들지 않고 준비 방법을 보여요.

  1. 관리자의 public/demo-media/grok-20261018/ 폴더를 만들어요.
  2. 본편 content-scene-01.mp4, 편성 schedule.json.js, 광고 영상 ad-coffee-6s.mp4, ad-earbuds-12s.mp4, ad-water-8s.mp4를 넣어요.
  3. schedule.json.js는 실행하는 스크립트가 아니라 raw 편성 JSON이에요. 영상 ID는 grok-demo-scene-01이어야 해요.

샘플 광고는 서버 루트가 public/일 때만 나와요. 샘플 편성의 광고 주소가 /demo-media/로 시작해서, 관리자를 /ads/처럼 경로 아래에 설치하면 광고 파일을 찾지 못하고 본편만 재생해요.

그누보드에서 쓰기

#‘그누보드에서 쓰기’ 절 주소

지금 되는 것

  • 관리자를 사이트 아래 /ads/처럼 설치해서 같은 출처로 써요. 관리자 로그인과 메뉴 권한은 그누보드의 것을 그대로 써요.
  • 영상 ID는 게시판:글번호:영상키 형식이에요. 영상키는 기본 main이고, 한 글에 영상이 여럿이면 설치 설정에서 영상키를 정해요.
  • 방문자가 그 글을 읽을 권한이 있어야 광고가 나와요. 읽기 포인트는 쓰지 않아요.
  • 설치 코드를 게시판 스킨이나 페이지에 직접 붙여 넣어요.
  • 하우스 광고, 지면 편성, 플레이어, 통계 메뉴가 동작해요.

준비 중인 것

  • 게시물에 플레이어를 자동으로 넣는 기능은 아직 없어요.
  • 광고 요청, 설정 메뉴는 화면만 있고 아직 동작하지 않아요(목업).
  • 프리셋 변경 이력과 되돌리기는 아직 없어요.

확인 필요: 쓰는 그누보드·영카트 버전에서 동작하는지, 게시물 본문에 설치 코드를 붙여 넣었을 때 그누보드가 script 줄을 남기는지는 설치한 사이트에서 확인해 주세요.

예전 정적 코드에서 옮기기

#‘예전 정적 코드에서 옮기기’ 절 주소

예전 정적 코드는 로더 없이 플레이어와 광고 요소를 페이지에 직접 넣던 방식이에요. 코드를 만들 때의 프리셋 값이 코드 안에 들어가서 프리셋을 바꿔도 따라 바뀌지 않아요. 이미 붙인 페이지는 그대로 동작해요.

  1. 예전 코드에서 영상 ID와 본편 주소를 찾아 둬요.
  2. 예전 코드의 플레이어 요소와 스크립트, 스타일 줄을 지워요.
  3. 그 자리에 설치 코드를 붙이고 같은 영상 ID(data-video-id)와 본편 주소(data-src)를 넣어요.
  4. 예전 코드와 다른 프리셋 모습이 필요하면 그 프리셋을 data-preset으로 고르거나 사이트에 적용해요.

문제 해결

#‘문제 해결’ 절 주소

콘솔에 [solad] 경고가 보일 때

  • "… 값은 쓸 수 없어 무시합니다": 그 data-* 값이 형식에 맞지 않아요. 나머지 값으로 재생해요.
  • "프리셋을 … 기본 설정으로 재생합니다": 프리셋을 받지 못했어요. 프리셋을 받지 못할 때를 봐 주세요.
  • "data-video-id가 없어…", "data-src가 없어…": 필수 값이 없어 그 자리는 플레이어를 만들지 않았어요.
  • "플레이어 파일을 불러오지 못했습니다": 관리자의 public/assets/를 확인해 주세요.

설정을 바꿨는데 그대로일 때(304)

프리셋 응답은 브라우저가 매번 서버에 바뀌었는지 물어보고, 바뀌지 않았으면 서버가 304로 답해요. 그래서 저장한 뒤 페이지를 새로고침하면 바로 바뀌어야 해요.

  • 그 자리가 data-preset으로 다른 프리셋을 쓰는지 확인해요.
  • 사이트에 적용한 프리셋이 바꾼 프리셋인지 확인해요.
  • 저장만 되고 아직 화면에 쓰지 않는 값(준비 중)인지 도움말에서 확인해요.
  • 확인 필요: 사이트 앞에 둔 캐시 서버나 CDN이 응답을 따로 저장하면 늦게 바뀔 수 있어요. 그 설정은 사이트에서 확인해 주세요.

자동재생이 막힐 때

자동재생은 늘 음소거로 시작해요. 그래도 브라우저 설정이나 절전 모드가 자동재생을 막으면 방문자가 재생 버튼을 눌러야 해요. 자세한 규칙은 자동재생과 음소거에 있어요.

광고가 나오지 않을 때

  • 자리 요소의 영상 ID가 지면 편성의 영상 ID와 같은지 확인해요.
  • 편성을 초안 저장만 하고 게시하지 않았는지 확인해요.
  • 위 단계의 편성이 광고를 끄도록 되어 있지 않은지 확인해요.
  • 그누보드에서는 방문자가 그 글을 읽을 권한이 있는지 확인해요.
  • 로더를 영상 페이지와 같은 사이트의 관리자에서 불러오는지 확인해요(같은 사이트에서만 동작).
  • 데모 샘플이라면 서버 루트가 public/인지 확인해요.
