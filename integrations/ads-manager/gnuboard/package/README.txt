솔애드 동영상 플레이어 · 광고 관리자 for 그누보드5  (버전 {{VERSION}})
====================================================================

설치 가이드와 사용 도움말은 docs 폴더의 HTML 파일을 브라우저로 열어 보세요.
  docs/install.html   설치 가이드
  docs/help.html      사용 도움말

필요 환경
  - 그누보드 5.6 이상 (5.6.43에서 확인)
  - PHP 8.2 이상, PDO MySQL·fileinfo·mbstring 확장
  - MySQL 5.7 이상 또는 MariaDB 10.3 이상
  - Apache 또는 nginx. 따로 설정할 것은 없습니다.
    (nginx 보안 설정은 선택: docs/nginx.conf.sample)
  - ffmpeg(선택): 커버 이미지·진행바 미리보기·하이라이트를 만들 때만 씁니다.

빠른 설치
  1. upload 폴더 "안의" 파일을 그누보드 루트(common.php가 있는 곳)에 그대로 올립니다.
     ads/  extend/  skin/  mobile/  theme/
     Apache라면 점으로 시작하는 .htaccess 파일(보안용)도 함께 올리면 좋습니다.
  2. 그누보드 최고관리자로 로그인한 뒤 https://내사이트/ads/setup.php 를 엽니다.
  3. 환경 점검이 모두 "확인"이면 "설치할 내용"의 두 칸을 체크한 채로 [설치하기]를 누릅니다.
     - 게시판 만들기: 동영상(video)·광고 요청(adreq) 게시판을 스킨과 설정까지 맞춰 만들고 메뉴에 넣습니다.
       스킨은 사이트 테마를 따릅니다. 밝은 테마(그누보드 기본 테마)는 solad_video_light, 솔애드 테마는 solad_video입니다.
     - 예제 넣기: 예제 영상 글 1개와 예제 하우스 광고(프리롤)를 넣습니다. 나중에 지워도 됩니다.
     광고 업로드 폴더(data/media)도 설치 화면이 만듭니다. 권한을 따로 바꿀 필요가 없습니다.
  4. 완료 화면의 [동영상 게시판 열기]에서 예제 글을 재생합니다. 프리롤 광고가 먼저 나오면 끝입니다.
  5. 내 광고는 관리자 > 게시판관리 > 솔애드 광고 관리에서 등록하고 편성합니다.

  직접 만들 때
    같은 이름의 게시판이 이미 있으면 설치 화면은 그 게시판을 고치지 않습니다.
    관리자 > 게시판관리에서 스킨을 solad_video(동영상), solad_request(광고 요청)로 고르고
    (밝은 테마(그누보드 기본 테마)는 solad_video_light, solad_request_light)
    파일 업로드 용량(기본 1MB)을 늘립니다. 자세한 값은 docs/install.html 6절에 있습니다.

업데이트
  새 버전의 upload 폴더를 덮어 올린 뒤 /ads/setup.php 에서 [DB 갱신]을 한 번 누릅니다.
  설정(data/solad/config.php)과 업로드한 광고(data/media)는 덮어쓰지 않습니다.
  1.0.1·1.0.2로 설치했다면 같은 화면의 [게시판 만들기]·[예제 넣기]로 게시판·메뉴·예제를 만들 수 있습니다.

1.0.0·1.0.1을 받았던 분
  덮어 올리기만 하면 예전 파일이 남으므로 아래 순서로 정리합니다.
  1. 관리자에서 올린 광고 파일이 있으면 data/media 폴더를 만들어 그곳으로 복사합니다.
     1.0.0은 ads/public/media, 1.0.1은 ads/media에 있습니다.
     이미 등록한 광고는 예전 주소(/ads/media/…)를 쓰므로, 1.0.0은 같은 파일을 ads/media에도 복사하고
     ads/media는 지우지 않습니다.
  2. ads 폴더 안의 public 폴더와 ads/.htaccess를 지웁니다.
  3. 이 버전의 upload 폴더를 덮어 올립니다.
  4. 이미 설치했다면 data/solad/config.php를 지운 뒤 /ads/setup.php 에서 [설치하기]를 다시 누릅니다.
     광고·편성·통계 표는 그대로 이어 씁니다.

라이선스
  구매한 사이트(도메인 1개)에서 사용할 수 있습니다. 재판매·재배포는 할 수 없습니다.
  포함된 Video.js는 Apache-2.0 라이선스를 따릅니다.
