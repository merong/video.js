## 컨텐츠 설명 (`it_explan`)

`description.html` 내용을 붙여 넣습니다.

1. `img/` 폴더의 이미지를 데모 사이트 등 공개 주소에 올립니다(예: `https://solad.oootool.com/solad-sirkr/img/`).
2. `description.html`의 `src="img/` 를 그 주소로 바꿉니다.
   ```bash
   sed 's#src="img/#src="https://solad.oootool.com/solad-sirkr/img/#g' description.html > description.sirkr.html
   ```
3. 맨 위 `<!-- … -->` 주석은 빼고 붙여 넣습니다.
