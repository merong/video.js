# REVIEW: 솔애드 플레이어 소개 영상 (56초)

## 만든 것과 만들지 않은 것

- 스토리라인 A(같은 화면이 다시 짜인다)를 56초로 확장했습니다. B(로고 사슬)와 C(끝없는 줌)는 만들지 않았습니다.
- 6번 장면은 동네 가게 사진 대신 커뮤니티 하우스 배너를 씁니다. 업로드 폼에 들어간 배너가 플레이어 이미지 광고(고정 배너)로 커집니다.
- 숫자는 모두 직접 그린 계량기이고 "예시 숫자", "예시 화면"으로 표시했습니다. 18820 통계가 비어 있기 때문입니다.

## 확인한 것

- `hyperframes check --json`: 통과(`ok: true`).
- `snapshot --review`의 장면별 시작·중간 화면과 컷 경계 화면을 직접 봤습니다.
- 이미지 배너 광고는 wr 2(삭제한 솔애드 샘플 영상)에서 wr 12(Oceans)로 옮겼습니다. 옮긴 뒤 wr 12에서 배너가 약 5초 동안 보이고 그동안 본편은 0초에 멈춰 있다가, 배너가 사라지면 본편이 재생되는 것을 화면 상태 값으로 다시 확인했습니다. 캡처 영상으로는 아직 보지 못했습니다.
- 소리: ElevenLabs Music v2.5로 만든 56초 연주곡 BGM 하나(`assets/audio/bgm.mp3`, 앞 0.3초 페이드 인, 끝 1.5초 페이드 아웃). 효과음은 없습니다.
  - 측정값: -16 LUFS, 트루 피크 -1.8 dBTP(원본 -0.3 dBTP를 리미터로 낮춤), 가장 큰 지점 44.5초, 소리는 54.3초에 끝남.
  - 앞부분(0~11.5초)이 생각만큼 조용하지 않습니다. 10~15초에 한 번 잦아들었다가 16초부터 커집니다.
  - 측정만 했고 들어 보지는 않았습니다. 히어로는 음소거 자동재생이라 방문자가 소리를 켤 때만 들립니다.

- **P1** · 0~4초 · 기본 플레이어에 브라우저 기본 컨트롤 막대가 없습니다 → r01 녹화로 바꿉니다.
- **P2** · 23.5초 · 밝은 관리자 바탕에서 다크로 넘어가는 중간 프레임이 회색으로 흐려 보입니다. 지나가는 프레임이라 두었습니다.
