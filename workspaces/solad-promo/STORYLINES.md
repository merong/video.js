# 솔애드 플레이어 홍보 영상: 스토리라인 3안

메인 페이지 히어로에 들어가는 45~55초 영상입니다. 16:9, 1920×1080, 30fps이며 자동재생이라 무음입니다.
화면은 개발 사이트(18820)에서 ego-lite 브라우저로 찍은 실제 화면만 씁니다. 통계 숫자는 개발 데이터라서 "예시 화면"으로 표시합니다.

전할 것(사용자 문구 그대로)
- MP4를 기본 플레이어로 올리면 사용자가 많이 봐도 트래픽 비용만 나간다.
- 광고를 붙여 동영상 게시판에서 수익을 낸다.
- 외부 플레이어가 아닌 자체 플레이어를 내 사이트답게 바꾼다. 사이트 로고도 넣는다.
- 유료 플레이어처럼 사용자 수나 재생 수로 과금하지 않고 무제한 쓴다.

사실 확인
- 광고는 자체 광고(하우스 광고)와, 광고주가 광고 요청 게시판으로 맡긴 광고를 편성하는 방식입니다. 광고 네트워크(VAST, 구글 광고) 연결은 없으므로 화면에 쓰지 않습니다.
- 특정 유료 플레이어의 이름이나 가격은 쓰지 않습니다.

## A. 같은 화면이 다시 짜인다 (추천)

- **장치와 형식:** 전과 후(Life before and after), 숫자가 바뀐다(A number lands). 형식은 한 화면이 스스로 다시 짜이는 방식(One frame that rebuilds)입니다.
- **무엇이 보이나:** 게시판 영상 한 편이 브라우저 기본 플레이어로 재생되고, 옆 계량기에는 재생 수가 오를 때마다 트래픽 비용만 쌓입니다. 같은 화면이 그 자리에서 솔애드 플레이어로 다시 짜이면 광고가 붙고, 같은 계량기가 광고 노출과 수익으로 뒤집힙니다.
- **첫 2초:** 기본 컨트롤만 있는 회색 플레이어가 재생 중이고, "재생 1,204회"가 올라가며 그 아래 "트래픽 비용"만 같이 오릅니다. 큰 제목은 "많이 볼수록, 비용만"입니다.
- **흐름:**
  1. 기본 플레이어와 비용 계량기
  2. 플레이어가 솔애드로 바뀌는 순간(공개)
  3. 프리롤 광고와 건너뛰기
  4. 관리자에서 광고 편성
  5. 로고를 네 모서리로 옮기고 테마 카드를 넘겨 플레이어가 바뀜
  6. 가운데 −10/+10
  7. 통계 숫자가 오르는 결과(가장 큰 장면)
  8. "사용자 수·재생 수 과금 없이 무제한"
  9. 끝 화면
- **룩:** 바탕은 솔애드 다크(#0F0F11)와 라임 강조(#CDF352)이고, 글자는 Noto Sans KR 700입니다. 실제 화면을 1.6~2배로 키워 보여 주고, 라임은 핵심 단어와 끝 화면에만 씁니다.
- **소리:** 히어로 자동재생이라 무음입니다. 큰 제목과 화면 속 실제 글자가 이야기를 끌고 갑니다.

## B. 로고 한 장이 플레이어를 바꾼다

- **장치와 형식:** 기능이 곧 첫 장면(The feature as the hook). 형식은 물건이 다음 장면을 여는 사슬(Object-to-object chain)입니다.
- **무엇이 보이나:** 첫 순간 "MY SITE" 로고가 날아와 재생 중인 영상 오른쪽 위에 딱 붙습니다. 그 로고가 관리자 모서리 선택칸이 되고, 테마 카드가 되고, 광고 건너뛰기 버튼이 되고, 통계 막대가 됩니다. 내 사이트다움에서 시작해 수익으로 끝나는 순서입니다.
- **첫 2초:** 재생 중인 영상 위로 로고가 떨어지며 모서리에 붙고, 제목 "이 플레이어, 내 사이트 거예요"가 뜹니다.
- **흐름:**
  1. 로고가 붙음
  2. 모서리 선택칸에서 위치 바꾸기
  3. 테마 카드 6장 사이를 이동
  4. 가운데 −10/+10
  5. 재생 버튼이 광고 건너뛰기 버튼으로 바뀜
  6. 광고 통계가 오름
  7. "재생 수 과금 없이"
  8. 끝 화면
- **룩:** 밝은 바탕(#F4F4F4)에 실제 화면을 크게 놓고, 장면이 바뀔 때마다 라임 테두리가 다음 물건을 짚습니다.
- **소리:** 무음입니다. 화면이 넘어가는 이유는 물건의 움직임으로 보여 줍니다.

## C. 끝없이 파고드는 줌 (과감한 안)

- **장치와 형식:** 결과부터 보여 주기(The result first). 형식은 끝없는 줌(An endless zoom)입니다.
- **무엇이 보이나:** 갤러리 썸네일 하나로 카메라가 파고들면 그 안이 플레이어고, 플레이어의 광고 배지로 파고들면 그 안이 관리자 편성 화면입니다. 편성표의 점 하나로 파고들면 통계 화면, 통계의 숫자 하나로 파고들면 다시 처음 갤러리가 나옵니다. 끊김 없이 반복되는 히어로에 맞는 형식입니다.
- **첫 2초:** 동영상 갤러리 전체 화면에서 썸네일 하나로 빠르게 밀고 들어가고, 제목 "이 영상, 돈이 됩니다"가 뜹니다.
- **흐름:**
  1. 갤러리로 들어감
  2. 플레이어(로고와 테마)
  3. 광고 배지로 들어감
  4. 편성 화면
  5. 통계
  6. "무제한"
  7. 갤러리로 돌아와 끝 화면 겸 처음 화면
- **룩:** 다크 바탕이고, 화면과 화면 사이를 라임 원형 마스크가 잇습니다.
- **소리:** 무음입니다. 리듬은 줌의 가속과 정지로 만듭니다.
