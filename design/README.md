솔애드 관리자는 운영자와 승인자가 광고 캠페인, 집행, 소재, 지면 편성을 다루는 관리 화면입니다. 색과 컴포넌트는 클래스픽 스튜디오(밝은 회색 바탕, 먹색 버튼, 라임 강조, 그림자 없는 면)를 그대로 따르고, 글자는 관리 화면에 맞게 한 단계 줄인 **균형** 규칙을 씁니다. 행이 많은 표에는 **밀집** 규칙을, 대시보드와 리포트 상단의 성과 숫자에는 **큰 수치** 규칙을 더합니다.

## 글자

글꼴은 두 가지입니다. 한글은 `sans`(Noto Sans KR), 숫자·날짜·영문 약어는 `num`(Inter)으로 씁니다. 두 글꼴은 `components/fonts.css`가 Google Fonts에서 불러옵니다(아래 "파일 구성" 참고). 설치 코드와 속성 이름은 `mono`(운영체제 고정폭 글꼴, 따로 불러오지 않음)의 `code`(12px/19px)로 씁니다.

- 페이지 제목은 화면마다 하나, `page-title`(20px/700)로 씁니다. 할 일 배너 제목은 `banner-title`로 같은 크기이고, 건수 숫자만 800 굵기에 `accent` 색입니다.
- 카드, 패널, 대화상자 제목은 `card-title`(14px/700)입니다.
- 본문과 입력값은 `body`(13px)입니다. 밀집 영역에서도 본문은 줄이지 않습니다.
- 입력 라벨, 칩, KPI 이름은 `label`(12.5px/500), 도움말과 오류 안내는 `small`(12px)입니다.
- 버튼 글자는 `button`(13px/600)이고 밀집 표 툴바에서는 12.5px입니다.
- 화면 안 굵기는 700까지 씁니다. 800은 로고와 배너 건수에만 씁니다.
- 12px보다 작은 글자는 차트 축 눈금(`axis`, 11.5px)에만 허용합니다.

### 세 가지 규칙과 화면별 적용

| 규칙 | 무엇이 바뀌나 | 쓰는 곳 |
| --- | --- | --- |
| 기본 (균형) | 컨트롤 `control-h` 34px, 표 행 `row-h` 42px, 표 셀 `cell` 13px, 숫자 `cell-num` 12.5px, 카드 여백 `pad-card` 18px | 캠페인 목록·상세, 집행 편집 단계형 폼, 소재 상세, 설정, 대화상자 |
| 밀집 | 컨트롤 `control-h-dense` 30px, 표 행 `row-h-dense` 36px, 표 셀 `cell-dense` 12.5px, 숫자 `cell-num-dense` 12px, 툴바 여백 `pad-card-dense` 14px | 승인함, 캠페인 상세의 집행 표, 지면 편성 목록, 소재 목록. **표 카드(툴바와 표)에만** 걸고 옆 패널과 폼은 기본으로 둡니다. |
| 큰 수치 | KPI 숫자 `kpi-hero` 26px/600 | 대시보드 오늘 요약, 리포트 상단 KPI 줄. 그 밖의 요약 카드는 `kpi`(20px/700)입니다. |

코드에서는 표 카드에 `sa-dense` 클래스를, KPI 줄에 `sa-kpis is-hero`를 붙입니다. 두 클래스를 화면 전체나 본문 문장에 걸지 않습니다.

## 색

- 바탕은 `bg`, 카드·표·입력란은 `panel`, 표 머리와 합계 행은 `panel-2`입니다. 면은 그림자 대신 `line` 테두리로 나눕니다.
- 글자는 `ink`, 보조 글자는 `sub`입니다. `faint`는 입력 안내 문구와 비활성 표시에만 씁니다.
- 기본 동작(승인 요청, 저장, 켜진 토글, 눌린 칩, 현재 메뉴)은 `primary`입니다. 밝은 테마에서는 먹색, 어두운 테마에서는 라임이며 글자는 `on-primary`입니다.
- 라임 `accent`는 화면당 한 번만 크게 씁니다. 집행 만들기 버튼, 기간제 태그, 배너 건수가 여기에 해당합니다. 라임 위 글자는 항상 `on-accent`(먹색)입니다.
- 글자로 쓰는 라임은 `accent-text`, 선택된 표 행 바탕은 `accent-soft`입니다.
- 좋아짐·나빠짐은 `good`·`bad`에 ▲/▼ 기호를 함께 씁니다. 노출이 늘어도 오류가 늘면 `bad`입니다. 색은 방향이 아니라 의미를 따릅니다.
- 제출을 막지 않는 검토 경고는 `warn`, 제출을 막는 검증 오류는 `bad`입니다.
- 할 일 배너는 `dark` 바탕에 `on-dark`·`dark-sub` 글자, 항목은 `dark-raised`, 반려 항목은 `bad-on-dark`입니다.

### 상태와 등급

- 상태는 아홉 가지이고 이름과 점 색을 고정합니다. 초안 `st-draft`, 승인 대기 `st-pending`, 예정 `st-scheduled`, 진행 `st-active`, 일시중지 `st-paused`, 종료 `st-done`, 미달 종료 `st-under`, 반려 `st-rejected`, 보관 `st-archived`. 점은 보조 표시이므로 상태 이름 글자를 항상 함께 씁니다.
- 등급 태그는 클래스픽의 멤버십·BEST·일반 태그를 따릅니다. 기간제는 라임 채움, 보장은 먹색 채움, 하우스는 테두리만 씁니다.

## 간격과 모양

- 카드 사이는 `gap-lg`(16px), 밀집 영역과 패널 안 입력란 사이는 `gap-md`(12px), 버튼 묶음은 `gap-sm`(8px), 라벨과 입력란 사이는 `gap-xs`(6px)입니다.
- 본문 영역 바깥 여백은 `pad-page`(24px), 카드 안쪽은 `pad-card`(18px), 배너 안쪽은 `pad-banner`(28px)입니다.
- 모서리는 태그·배지 `radius-tag`(4px), 버튼·입력란·칩 `radius-control`(8px), 카드 `radius-card`(12px), 할 일 배너 `radius-banner`(20px)입니다.
- 그림자는 쓰지 않습니다. 토글 손잡이의 `shadow-knob`만 예외입니다.

## 문구

- 버튼은 하는 일을 그대로 적습니다. "승인 요청", "초안 저장", "집행 만들기", "승인함 열기".
- 안내와 배너는 해요체로 짧게 씁니다. "김운영 님, 확인할 일이 11건 있어요".
- 오류는 무엇이 문제인지와 고치는 방법을 함께 적습니다. "캠페인 기간(11.30까지)을 넘습니다. 11.30 이전으로 바꿔 주세요."
- 숫자는 천 단위 쉼표를 찍고(102,300), 비율 차이는 %p로 씁니다(▲ 0.6%p). 날짜는 `10.20`, 기간은 `10.01 – 11.30`, 남은 날은 `D-4`로 씁니다.
- 오늘 수치는 기준 시각을 함께 적고, 비교는 "어제 같은 시각"과 합니다.

## 접근성

- 키보드 초점은 `focus-ring` 2px 실선에 2px 간격입니다. 밝은 테마에서는 먹색, 어두운 테마에서는 라임이며 모든 면에서 3:1 이상입니다.
- `line-2` 컨트롤 테두리는 클래스픽 원래 값이라 3:1에 못 미칩니다. 컨트롤은 글자와 바탕 차이로도 알아볼 수 있게 둡니다.
- 모든 차트에는 같은 데이터의 표 보기를 둡니다. 추이 카드의 "표" 칩이 그 역할입니다.
- 토글은 `role="switch"`와 `aria-checked`, 칩은 `aria-pressed`, 현재 메뉴는 `aria-current="page"`로 상태를 알립니다.

## 움직임

- 시간은 `motion-*` 토큰을 씁니다. 조작 반응(hover, 토글)은 `motion-fast`(150ms), 도움말 그림은 한 번 도는 것이 `motion-help-once`(5초), 반복하는 것이 `motion-help-loop`(8초)이고 가속은 `ease-standard`입니다.
- 움직임은 `@media (prefers-reduced-motion: no-preference)` 안에서만 붙입니다. 움직임 줄이기 설정에서는 핵심 상태 한 장을 보여 줍니다.
- 5초를 넘거나 반복하는 움직임에는 일시정지와 다시 보기를 두고, 화면 밖에서는 멈춥니다. 1초에 3번 넘게 깜빡이는 움직임은 쓰지 않습니다. 자세한 규칙은 `components/HelpMotion/README.md`에 있습니다.

## 아이콘과 로고

- 아이콘은 16px 선 아이콘(선 굵기 1.5, 둥근 끝)을 `currentColor`로 씁니다. 정해진 아이콘 세트가 없어 미리보기에는 같은 규격으로 그린 임시 아이콘을 넣었습니다. 실제 세트가 정해지면 교체합니다.
- 로고는 "솔애드" 글자(800)와 라임 "관리자" 태그를 붙인 글자 로고입니다. 로고 그림 파일이 정해지면 같은 자리에 넣습니다. 브라우저 탭 제목은 "솔애드 관리자"입니다.

## 파일 구성

저장소의 `design/` 폴더가 원본입니다.

| 파일 | 내용 |
| --- | --- |
| `tokens.json` | 색, 글자, 간격, 모양, 크기 토큰의 원본. 값은 여기서만 바꿉니다. |
| `tokens.css` | `tokens.json`에서 만든 CSS 변수. 직접 고치지 말고 `node design/build-tokens.mjs`로 다시 만듭니다. |
| `components/bundle.css` | 컴포넌트 스타일(`sa-` 접두사). 색·간격·모양은 `tokens.css` 변수만 쓰고, 글자 크기는 `tokens.json` 글자 스타일과 같은 값을 씁니다. |
| `components/fonts.css` | 웹 글꼴(Noto Sans KR, Inter)을 Google Fonts에서 불러오는 `@import` 한 줄. |
| `components/<이름>/README.md` | 컴포넌트 사용 규칙. |
| `components/<이름>/preview.html` | 컴포넌트 미리보기. 브라우저에서 바로 열 수 있습니다. |
| `index.html` | 모든 미리보기를 모아 보는 페이지. |

화면에서 쓸 때는 관리자 앱과 미리보기 모두 `components/fonts.css`, `tokens.css`, `components/bundle.css` 순서로 불러옵니다.

- 외부 글꼴을 쓸 수 없는 설치 환경에서는 `fonts.css`만 빼면 됩니다. 글자는 `tokens.css`의 `--font-sans`, `--font-num` 목록에 있는 시스템 글꼴(Apple SD Gothic Neo, Malgun Gothic 등)로 표시됩니다.
