# ColorField

색 고르기 칸과 `#rrggbb` 글자 입력을 한 라벨로 묶은 입력란입니다. 플레이어 프리셋의 강조색, 강조 글자색, 테두리 색, 광고 강조색에 씁니다.

- 구조: `div.sa-field` > `label.sa-label#<id>-label[for=<글자 입력 id>]`, `div.sa-color` > `span.sa-color-swatch > input[type=color]`, `input.sa-input`, 그리고 `button.sa-btn.is-sm`(지우기) 또는 `span.sa-color-state`(기본값 사용). 아래 `span.sa-help`는 `Field`와 같습니다.
- 이름: 글자 입력은 라벨 그대로("강조색"), 색 고르기는 `aria-labelledby`로 "강조색 색 고르기", 지우기 버튼은 "강조색 지우기"입니다. 같은 화면에 색 입력란이 여러 개여도 이름이 겹치지 않습니다.
- 두 입력은 같은 값을 따릅니다. 값은 항상 소문자 `#rrggbb`로 내보냅니다. 대문자로 입력해도 소문자로 바뀝니다.
- 비운 값(`null`)은 "기본값 사용"입니다. 색 칸을 비우고 빗금 한 줄을 긋고(`.sa-color.is-empty`), 지우기 버튼 자리에 상태 문구를 둡니다. 상태 문구는 두 입력의 `aria-describedby`에 연결합니다. 비운 상태에서도 색 칸을 누르면 색 고르기가 열립니다.
- 글자 입력이 형식에 맞지 않으면 값을 내보내지 않고, 입력란을 벗어나거나 Enter를 누를 때 오류 문구("#과 16진수 6자리로 입력해 주세요. 예: #cdf352")를 `aria-describedby`로 연결합니다. 고치는 대로 오류가 사라집니다. 오류가 있는 동안 화면이 가진 값은 마지막으로 맞았던 값입니다.
- 대비 경고처럼 저장을 막지 않는 안내는 `is-warn`(경고 문구)으로 둡니다.
- 색 칸은 overflow로 잘리므로 초점 링은 칸 바깥(`.sa-color-swatch:has(input:focus-visible)`)에 그립니다.
- "광고 강조색"(`ads.accentColor`, 결정 26)은 예전 이름 "광고 음량 막대 색"을 바꾼 것입니다. 광고 음량 막대와 광고 진행 막대가 함께 씁니다. 비우면 "기본값 사용 · 테마 강조색"을 상태 문구로 둡니다. 필드 이름은 바뀌지 않습니다.

## 테두리 색과 "테두리 없음" (A2-E)

`theme.borderColor`(테두리 색)만 투명도가 있는 8자리를 받습니다(명세 1.3). 다른 색 필드는 6자리 그대로입니다.

- 글자 입력은 `#rrggbb`와 `#rrggbbaa`를 받고 소문자로 내보냅니다. 형식 오류 문구는 "#과 16진수 6자리로 입력해 주세요. 투명도를 넣으려면 8자리로 써요. 예: #cdf352, #00000026"입니다(테두리 색에서만).
- 색 고르기 칸은 투명도를 다루지 못합니다. 8자리 값이면 앞 6자리 색을 불투명하게 보이고, 칸에서 고르면 투명도가 빠진 `#rrggbb`가 됩니다. 값에 투명도가 있을 때(`aa`가 `ff`가 아니고 `00`도 아님) 도움말 "색 칸은 투명도를 보이지 못해요. 색 칸에서 고르면 투명도가 빠져요."를 두 입력의 `aria-describedby`에 더합니다.
- 바로 아래에 Check(`label.sa-check > input[type=checkbox]`) "테두리 없음"과 도움말 "켜면 플레이어 둘레에 선을 그리지 않아요."를 둡니다. 체크박스의 `aria-describedby`로 잇습니다.
  - 켜면 값은 `#00000000`입니다. 색 칸과 글자 입력은 `disabled`로 막고 지우기 버튼은 없앱니다. 색 칸은 `.sa-color.is-none`으로 빗금 한 줄(기본값 사용과 같은 그림)을 긋고, 글자 입력에는 `#00000000`이 그대로 보입니다. 비운 값(기본값 사용)과는 글자 입력의 값으로 구별됩니다.
  - 끄면 비운 값(`null`, 스킨 기본 · 10% 검정)으로 돌아갑니다. `is-empty`와 지금 테두리 색의 상태 문구(편집기 ColorField의 기본 "기본값 사용")를 그대로 둡니다. 켜기 전 값으로 돌아가지 않습니다(명세 1.3).
  - 저장된 값의 투명도가 `00`이면 체크가 켜진 채 열립니다. `#ff000000`처럼 색이 있어도 같습니다(선이 보이지 않으므로).
  - 초점은 체크박스에 남습니다. 막힌 칸의 이유는 바로 아래 체크박스라 DisabledReason 문장을 따로 두지 않습니다.
