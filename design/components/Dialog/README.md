# Dialog

반려 사유 입력, 되돌릴 수 없는 동작 확인처럼 지금 화면을 잠시 멈추고 답을 받는 대화상자입니다. 네이티브 `dialog`를 `showModal()`로 엽니다.

- 클래스: `dialog.sa-dialog` 안에 `sa-dialog-h`(제목 `sa-card-title`과 닫기 버튼), `sa-dialog-b`(본문), `sa-dialog-f`(버튼)를 둡니다.
- 제목은 `aria-labelledby`로 잇습니다. Esc와 닫기 버튼으로 닫히고, 닫으면 연 버튼으로 포커스가 돌아갑니다.
- 폭은 480px(화면이 좁으면 양옆 16px 여백)입니다. 그림자 없이 테두리와 어두운 배경막만 씁니다.
- 되돌릴 수 없는 동작 버튼은 `is-danger`, 취소는 기본 버튼입니다.

## 사이트에 적용 확인 (A2)

틀은 그대로이고 내용만 다릅니다. 사이트 전체의 플레이어가 바뀌는 동작이라 확인을 받습니다.

- 제목은 "<프리셋 이름>을 사이트에 적용할까요?"입니다. 본문 첫 줄에 "로더를 넣은 사이트의 모든 플레이어가 이 프리셋으로 바뀌어요. 방문자가 페이지를 새로고침하면 바로 보여요."를 두고, 아래 KeyValue(`sa-kv`)로 "지금 사이트 적용"과 "바꿀 프리셋"(이름 · 플레이어 종류 · 화면 언어)을 보입니다.
- 처음 초점은 **취소**에 둡니다(`autofocus`). 실수로 Enter를 눌러도 사이트가 바뀌지 않게 하려는 것입니다.
- 적용 버튼은 `is-primary`입니다. 다른 프리셋을 다시 적용하면 되돌릴 수 있는 동작이라 `is-danger`를 쓰지 않습니다.
- 적용 중에는 두 버튼을 `disabled`로 막고 바닥줄 왼쪽에 StatusMessage(`sa-status`)로 "적용하는 중…"을 알립니다. `.sa-dialog-f > .sa-status`는 왼쪽으로 붙습니다.
- 성공하면 닫고 목록의 상태 문구(`sa-status.is-good`)로 "이벤트 페이지를 사이트에 적용했어요. 페이지를 새로고침하면 바뀐 플레이어가 보여요."를 알립니다. 실패하면 닫지 않고 `sa-status.is-bad`(`role="alert"`)에 "사이트에 적용하지 못했어요. 지금 사이트 적용 프리셋은 공지 영상 그대로예요. 잠시 뒤 다시 눌러 주세요."처럼 지금 상태와 다시 하는 방법을 적습니다.
- 닫으면 연 버튼으로 초점이 돌아갑니다. 성공으로 그 버튼이 막혀도 `aria-disabled`라 초점을 받으므로 그 버튼에 돌려놓습니다. 이유 "지금 적용된 프리셋이에요"가 함께 읽힙니다.

## 플레이어 미리보기 (A2-E, 넓은 변형)

프리셋 목록의 "미리보기"가 여는 대화상자입니다. 플레이어를 담아야 해서 넓은 변형 `dialog.sa-dialog.is-wide`를 씁니다. 다른 대화상자는 지금처럼 480px입니다.

- 폭: `min(740px, 100vw - 32px)`, 브라우저 기본 `max-width`는 풉니다. 1280에서 740px(무대 자리 폭 702px, "보통 · 768"은 91%로 줄여 보임), 768에서 736px, 600px 이하에서는 화면 폭 - 16px(양옆 8px)이고 머리·본문·바닥줄 좌우 여백이 `gap-md`(12px)로 줄어 390에서 374px입니다. 1280×800 화면에서는 저장 안내(Note)가 있어도 본문이 스크롤 없이 들어갑니다.
- 높이: 최대 `100dvh - 32px`(600px 이하 `- 16px`). 머리와 바닥줄은 늘 보이고 본문(`sa-dialog-b`)만 세로로 스크롤합니다. 본문이 최대 높이를 넘으면 무대 자리(`sa-stage-view`)의 폭을 `--_fit`으로 줄여(16:9 그대로, 가운데) 맞추고, 폭 안내는 "높이에 맞춘 자리 폭 Npx · 실제 크기예요"가 됩니다. 512px(32rem, 더 좁으면 스킨이 자막 버튼을 숨겨 넓은 플레이어 모양이 아님)에서 멈추고, 그래도 넘치면 본문이 스크롤합니다.
  - 1280×800: Note도 "페이지 언어"도 없으면 자리 폭 702px 그대로입니다. 플레이어 언어가 빈 프리셋(내장 프리셋 포함)은 "페이지 언어" Field(84px + 간격 12px)가 더 있어 자리 폭이 640px, Note까지 있으면 551px입니다.
  - 1280×720: 512px에서 멈추고 본문이 조금 스크롤합니다("페이지 언어"가 있을 때 Note 없음 8px, 있음 58px).
  - 768·390 폭에서는 화면 폭이 먼저 모자라 줄이지 않습니다.
- 구조: `dialog.sa-dialog.is-wide[aria-labelledby][aria-describedby?] > form[method=dialog]` 안에
  1. `sa-dialog-h`: `div.sa-dialog-title`(제목 "<이름> 미리보기" `sa-card-title` + `span.sa-small` "저장된 값 · 통계에 남기지 않아요", 좁으면 제목 아래로 내려감) + 닫기 아이콘 버튼(`aria-label="닫기"`).
  2. `sa-dialog-b`: PlayerPreview 본문(PlayerPreview README "프리셋 목록 미리보기 대화상자").
  3. `sa-dialog-f`: 왼쪽 "데모에서 열기"(`a.sa-btn.is-start`, 새 창, `sa-sr` " (새 창)"), 오른쪽 "닫기"(`value="close"`). `.sa-dialog-f > .is-start`가 왼쪽으로 붙입니다.
- 저장하지 않은 입력이 있는 프리셋: 본문 맨 위 Note(`p.sa-note[role=note][id]`) "<b>저장된 값으로 보여요.</b> 이 프리셋에는 저장하지 않은 입력이 있어요. 편집 화면에서 저장하면 여기에도 보여요."를 두고 대화상자의 `aria-describedby`로 잇습니다. 열 때 제목과 함께 읽힙니다. 없으면 Note와 `aria-describedby`를 뺍니다.
- 처음 초점: 머리의 닫기 아이콘 버튼(`autofocus`). 대화상자 이름과 설명(Note)이 먼저 읽히고, 다음 Tab이 폭 보기로 갑니다. 플레이어(iframe)에 초점을 두지 않습니다. 열자마자 키 입력이 플레이어로 가면 재생·음량이 바뀝니다.
- 닫기: Esc, 닫기 아이콘, 바닥줄 "닫기". 닫으면 연 "미리보기" 버튼으로 초점이 돌아갑니다. 그 사이 목록을 다시 불러 버튼이 없어졌으면 같은 이름의 행의 "미리보기", 그 행도 없으면 목록 제목(`tabindex="-1"`)으로 둡니다.
- 닫으면 iframe을 지워 플레이어를 없앱니다(소리가 남지 않게). 바깥(배경막)을 눌러 닫지 않습니다. 다른 대화상자와 같습니다.
- 미리보기 화면에서 `#preview`로 열면 이 대화상자가 바로 열립니다(확인용).
