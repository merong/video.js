자리 요소 data-* 속성

이름 받는 값 기본값 설명 적용 단계
data-solad-player#‘data-solad-player’ 항목 주소 받는 값있음 기본값없음(필수) 설명로더가 플레이어를 만들 자리예요. 한 페이지에 여러 개 둘 수 있어요. 적용 단계적용
data-video-id#‘data-video-id’ 항목 주소 받는 값문자열, 128자 이하 기본값없음(필수) 설명편성과 통계에 쓰는 고정 영상 ID예요. 적용 단계적용
data-preset#‘data-preset’ 항목 주소 받는 값프리셋 id 기본값사이트 적용 프리셋 설명이 자리만 다른 프리셋으로 만들어요. 사이트 적용 프리셋을 쓸 때는 넣지 않아요. 적용 단계적용
data-autoplay#‘data-autoplay’ 항목 주소 받는 값true | false 기본값프리셋 값, 없으면 false 설명자동재생이에요. 켜면 늘 음소거로 시작해요. 적용 단계적용
--ads-accent-color#‘--ads-accent-color’ 항목 주소 받는 값CSS 색 기본값테마 강조색 설명광고 음량 막대와 진행 막대 색이에요. 적용 단계적용
