# TodoBanner

대시보드 맨 위의 운영 할 일 배너입니다. 클래스픽 스튜디오의 어두운 배너를 그대로 씁니다.

- 바탕 `dark`, 모서리 `radius-banner`(20px), 안쪽 여백 `pad-banner`입니다. 제목은 `banner-title`(22px/700)이고 건수만 800 굵기에 `accent`입니다.
- 항목은 소재 심사 대기, 지면 편성 승인 대기, 집행 승인 대기, 7일 안에 종료되는 캠페인, 내 제출 중 반려 다섯 가지입니다. 각 항목은 해당 화면으로 연결합니다.
- 건수 칩은 `accent`, 반려 항목은 `is-bad`로 `bad-on-dark` 테두리 칩을 씁니다.
- 할 일이 0건이면 배너 대신 "확인할 일이 없어요" 한 줄 카드로 바꿉니다. 페이싱 경고는 여기에 두지 않습니다.
