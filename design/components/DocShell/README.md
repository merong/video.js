# DocShell

공개 페이지(데모 `index.html`, 설명서 `guide.html`, 도움말 `help.html`)의 틀입니다. 위쪽 탐색, 목차, 본문, 제목 앵커로 이뤄집니다. 재생 테스트 페이지(`play-test.html`)도 같은 위쪽 탐색을 쓰고 목차는 두지 않습니다.

## 위쪽 탐색

- TopNav(`header.sa-top`)를 그대로 씁니다. `nav.sa-nav[aria-label="플레이어 문서"]` 안에 데모 · 설명서 · 도움말 링크 셋을 두고 현재 페이지에 `aria-current="page"`를 붙입니다. 재생 테스트 페이지에서는 셋 다 현재가 아닙니다.
- 오른쪽(`sa-top-r`)에는 "관리자 열기" 기본 버튼 하나만 둡니다(`a.sa-btn.is-sm`). 라임 버튼과 검색, 사용자 표시는 두지 않습니다. 주소는 구현이 정합니다.
- 960px 이하에서는 TopNav 규칙대로 메뉴가 두 번째 줄로 내려갑니다. 링크가 셋이라 390에서도 넘치지 않습니다.

### 로고: `솔애드 <em>플레이어</em>`

- 구조는 `sa-logo`와 같고, 라임 태그 글자만 "관리자" 대신 "플레이어"입니다. 브라우저 탭 제목은 "<페이지> · 솔애드 플레이어"입니다(예: "도움말 · 솔애드 플레이어").
- 이유
  - 이 페이지들은 로그인하지 않은 방문자도 열 수 있고, 관리 메뉴가 없습니다. "관리자" 태그를 달면 관리자 화면으로 오해하고 로그인 없이 열린 것을 오류로 여길 수 있습니다.
  - 읽는 사람은 사이트에 플레이어를 붙이는 개발자와 운영자입니다. 페이지가 다루는 것(플레이어)을 태그로 알립니다.
  - 태그 글자를 바꾸는 선례가 있습니다. 그누보드 팝업은 같은 자리에 `[사이트 이름] <em>광고 관리</em>`를 씁니다(TopNav).
- 관리자 플레이어 미리보기(`preview.html`)는 관리자 화면 안의 iframe이라 로고와 위쪽 탐색을 두지 않습니다. 단독으로 열었을 때의 안내 화면에도 두지 않습니다.

## 목차

- 구조: `details.sa-disclosure.sa-toc[open] > summary("이 페이지 목차") + nav.sa-secnav[aria-label="이 페이지 목차"]`. Disclosure와 SectionNav를 그대로 쓰고, `sa-toc`는 붙임과 안쪽 여백만 바꿉니다.
- 넓은 폭(961px 이상): 본문 왼쪽 220px 열에 `position: sticky`로 붙습니다. 목차가 화면보다 길면 목차 안에서 세로로 스크롤합니다.
- 960px 이하: 본문 위로 올라가고 처음에는 접혀 있습니다. 페이지가 열릴 때 스크립트가 `open`을 끕니다. 스크립트가 없으면 열린 채로 남아 목차가 사라지지 않습니다.
- 접기 칸을 쓴 이유: 네이티브 `details`라 Enter·Space로 열고 닫히고 열림 상태를 브라우저가 알립니다. `aria-expanded`를 따로 맞출 필요가 없습니다. 넓은 폭에서 접어도 해가 없어 폭마다 다른 부품으로 바꾸지 않습니다.
- 지금 읽는 절의 링크에 `aria-current="true"`를 붙입니다(SectionNav와 같습니다). 같은 페이지 안 이동이라 `"page"`를 쓰지 않습니다.
- 목차 항목은 `h2` 절만 넣습니다. 옵션 행(`#opt-…`, `#field-…`)은 넣지 않습니다.

## 본문

- `div.sa-doc` > `details.sa-toc` + `main.sa-doc-body`. 본문 맨 위 `div.sa-doc-head`에 `h1.sa-page-title`과 한두 문장 소개를 둡니다.
- 절은 `section.sa-doc-sec[aria-labelledby]`이고 위에 `line` 한 줄을 긋습니다. 문단과 목록은 72자 폭으로 끊고, 표와 코드 블록은 본문 폭을 다 씁니다.
- 제목은 `h2.sa-doc-h`(14px/700), 절 안 소제목은 `h3.sa-doc-h3`(13px/700)입니다. 화면 제목만 20px입니다.
- 긴 코드는 CodeBlock, 표는 OptionTable 또는 DataTable을 씁니다. 둘 다 안에서 가로로 스크롤하거나(코드) 카드로 바뀌어(옵션 표) 페이지 가로 스크롤을 만들지 않습니다.

## 제목 앵커

- 구조: `div.sa-doc-hrow > h2[id] + a.sa-anchor[href="#id"]`. 링크 안에 보이는 `#`(`aria-hidden`)와 화면 읽기용 "‘<제목>’ 절 주소"(`sa-sr`)를 둡니다. 옵션 행과 소제목은 "‘<이름>’ 항목 주소"입니다.
- 링크를 제목 밖에 두는 이유: 제목 안에 넣으면 제목 목록에서 "설치 코드 두 줄 ‘설치 코드 두 줄’ 절 주소"처럼 이름이 길어집니다.
- `#`는 늘 보입니다(`faint`, 마우스를 올리면 `ink`). 마우스를 올릴 때만 보이면 터치 화면과 키보드에서 찾기 어렵습니다. 누르는 면은 24px입니다.
- **복사 버튼은 두지 않습니다.** 앵커는 그냥 링크입니다. 누르면 주소창이 그 절 주소로 바뀌고, 브라우저의 "링크 주소 복사"로 복사합니다.
  - 이유: 클립보드는 보안 연결(https)이 아닌 설치 사이트에서 막히는데, 제목마다 실패 안내를 둘 수 없습니다. 절마다 결과 알림이 생기면 화면 읽기 프로그램이 시끄러워집니다. 관리자 화면은 이 앵커로 바로 링크하므로 주소 자체가 정확하면 됩니다.
- 고정 앵커(명세 4절): 절 `#install`, `#attributes`, `#js-api`, `#events`, `#precedence`, `#autoplay`, `#language`, `#preset-fields`, `#failure`, `#same-origin`. 설치 옵션 `#opt-<이름>`, 프리셋 필드 `#field-<경로>`. 설명서 절은 `ads-demo-copy.md`의 앵커를 씁니다.
- 위쪽 탐색은 붙지 않으므로 `scroll-margin-top`은 `gap-lg`(16px)만 둡니다.

## 단계 표시

- 준비 중인 절이나 옵션에는 PhaseTag(`span.sa-phase`)를 제목 줄 또는 표의 "적용 단계" 칸에 둡니다.

## 폭

- 1280: 목차 220px + 간격 32px + 본문. 본문 최대 폭은 `sa-doc` 1200px 안입니다.
- 768·390: 한 열, 양옆 16px. 목차는 본문 위에서 접힙니다.
