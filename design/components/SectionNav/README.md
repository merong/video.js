# SectionNav

프리셋 편집기의 일곱 구획(기본, 테마, 로고, 컨트롤, 재생 동작, 언어, 광고 화면) 사이를 옮겨 다니는 목록입니다. 폭에 따라 모양만 바뀌고 순서와 이름은 같습니다.

- 1280: `nav.sa-secnav[aria-label="편집 구획"]` 세로 목록. 편집 칸 왼쪽에 `position: sticky`로 붙입니다(붙이는 일은 화면 레이아웃이 합니다).
- 768: `nav.sa-secnav.is-row` 칩 줄. 줄이 넘치면 다음 줄로 내려가고 가로 스크롤은 만들지 않습니다.
- 390: `div.sa-secjump` 안의 `select.sa-input`. 라벨은 "구획으로 이동"이고, 고르면 그 구획으로 옮겨 갑니다.
- 각 항목은 같은 문서 안 구획으로 가는 `a[href="#…"]`입니다. 지금 보이는 구획에 `aria-current="true"`를 붙입니다. 페이지 이동이 아니므로 `"page"`를 쓰지 않습니다.
- 고칠 칸이 있는 구획은 `span.sa-secnav-err`에 "오류 N"을 글자로 씁니다. 점 색만으로 알리지 않습니다. select에서는 항목 이름에 "· 오류 N"을 붙이고 아래 `sa-help`에 문장으로 다시 적습니다.
- 기본 video 프리셋에서 쓸 수 없는 구획은 `a.is-off`로 흐리게 두고 링크는 살려 둡니다. 옮겨 가면 그 구획의 DisabledReason이 이유를 알려 줍니다. 링크 글자에 "쓸 수 없음"을 함께 씁니다.
- 근거: 캔버스 B(편집기 1280·768·390), 명세 6.5절.
