# Stepper

집행 편집 단계형 폼의 단계 목록입니다. 기본 → 기간·요일·시간대 → 등급별 조건 → 타겟 → 소재 연결 → 스킵 정책 → 검토·제출 순서입니다.

- 구조: `ol.sa-steps` 안에 단계별 `li`. 현재 단계는 `aria-current="step"`, 끝난 단계는 `is-done`, 검증 오류가 남은 단계는 `is-error`입니다.
- 번호는 CSS 카운터가 매깁니다. 순서가 실제 작업 순서이므로 번호를 지우지 않습니다.
- 폼 영역은 기본 밀도(`control-h` 34px, 본문 13px)입니다. 아래 줄에 이전, 초안 저장, 다음 단계 이름을 적은 `is-primary` 버튼을 둡니다.
- 검토 단계의 경고(`warn`)는 제출을 막지 않고, 검증 오류(`bad`)는 막습니다.
- 요청 접수 → 검토 → 승인 → 집행 → 종료처럼 처리 흐름을 한 줄로 보여 줄 때는 가로형 `ol.sa-flow`를 씁니다. 같은 `is-done`, `aria-current="step"` 규칙을 따릅니다.
