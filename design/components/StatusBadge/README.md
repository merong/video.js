# StatusBadge

캠페인, 집행, 소재, 지면 편성의 상태를 보여 주는 배지입니다. 상태 이름과 점 색은 모든 화면에서 같습니다.

- 구조: `span.sa-badge[data-st]`. 값은 `draft`, `pending`, `scheduled`, `active`, `paused`, `done`, `under`, `rejected`, `archived`이고 점 색은 `st-*` 토큰입니다.
- 점은 보조 표시입니다. 상태 이름(초안, 승인 대기, 예정, 진행, 일시중지, 종료, 미달 종료, 반려, 보관)을 항상 글자로 씁니다.
- 수정본이 승인 대기 중이면 "수정본 r4 승인 대기"처럼 배지 글자에 버전을 붙일 수 있습니다.
- 글자는 12px/500, 등급 태그보다 가볍게 둡니다.

## 플레이어 프리셋 표시 (A2)

프리셋 목록에는 상태가 아니라 표시 두 가지를 씁니다. 아홉 상태(`data-st`)와 섞지 않고 수식어 클래스로 붙입니다.

- 사이트 적용: `span.sa-badge.is-site`. `primary` 채움에 `on-primary` 글자, 점도 글자색입니다. 사이트 전체에 쓰이는 프리셋 한 개에만 붙습니다(예전 "기본" 배지).
- 옮김: `span.sa-badge.is-moved`. 점선 테두리에 `sub` 글자입니다. 중립 스킨에서 이전된 프리셋에 "중립 스킨에서 옮김"으로 붙고, 목록의 한 번만 보이는 안내(Note `has-actions`)와 함께 씁니다.
- 내장 프리셋 표시는 기존 배지(`data-st` 없이 초안 점)를 그대로 씁니다.
