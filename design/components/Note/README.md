# Note

폼이나 패널 안에서 미리 알아 둘 점을 적는 안내 메모입니다. 처리 결과를 알리는 문구는 StatusMessage를 씁니다.

- 클래스: `p.sa-note` 또는 `div.sa-note`, 종류 `is-warn`(주의) / `is-bad`(막힘). 앞머리 요약은 `b`로 감쌉니다.
- 정적인 안내라 `role="note"`를 붙이고, 화면 읽기 프로그램이 따로 읽어 주지 않아도 되는 내용만 적습니다.
- 글자는 small 12.5px, 바탕은 `panel-2`입니다.
- 한 번만 보이는 안내(A2, 중립 스킨 이전 안내)는 `div.sa-note.has-actions`에 글 `span`과 `div.sa-note-actions`(버튼 2개)를 둡니다. 좁으면 버튼 줄이 글 아래로 내려갑니다. "확인"을 누르면 안내를 숨기고 다시 보이지 않으며, 초점은 목록 제목으로 옮깁니다.
