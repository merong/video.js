# PlayerStage

데모, 재생 테스트, 관리자 플레이어 미리보기가 함께 쓰는 플레이어 무대입니다. 고른 폭으로 플레이어를 그리고, 자리보다 넓으면 줄여 보이며 줄인 비율을 글자로 적습니다. 아래에 장면 바로가기와 최근 광고 진행 한 줄을 둡니다.

- 구조: `section.sa-stage[aria-labelledby]` 안에 차례로
  1. `div.sa-stage-bar`: 폭 보기 Segmented(`sa-seg`, 라벨 "폭 보기") + 비율 글자 `p.sa-small[id]`. 비율 글자는 묶음의 `aria-describedby`로 잇습니다.
  2. `div.sa-stage-view` > `div.sa-stage-frame` > 플레이어(데모·재생 테스트) 또는 `iframe`(관리자 미리보기).
  3. `div.sa-stage-tools`: `span.sa-label` "장면 바로가기" + `div.sa-row[role=group][aria-labelledby]` 안의 `button.sa-btn.is-sm` 셋.
  4. `p.sa-stage-now`: "최근 광고 진행" + 내용 + `time`.
  5. 상태 문구 StatusMessage(`p.sa-status`)는 무대 위나 아래 한 곳에 둡니다.
- 무대(`sa-stage-view`)는 플레이어 위에 모서리, 선, 모서리 잘라내기를 더하지 않습니다(A2-E, 명세 1.1). 프리셋의 모서리(기본 스킨 28px, 플랫 0, 둥근 테두리 12px)와 테두리가 고객 페이지에서처럼 보여야 하기 때문입니다.
  - 배경 `panel-2`만 깝니다. 플레이어 모서리 바깥과, 좁게 볼 때 플레이어 양옆에 이 배경이 보여 모서리 모양이 드러납니다.
  - `overflow: hidden`은 남깁니다. 줄인 프레임의 원래 폭이 페이지를 넓히지 않게 하려는 것이고, 무대에 모서리가 없으니 플레이어를 자르지 않습니다.
  - iframe 안 페이지(`examples/preview.html`)와 데모의 플레이어 자리(`demo.css`의 `.ex-player`, `.ex-frame`)도 모서리·선·그림자를 더하지 않고, iframe 안 `body` 배경은 비워(투명) 이 무대 배경이 보이게 합니다. 이 파일들은 `design/` 밖이라 구현 담당이 맞춥니다.
  - 어두운 테마에서는 배경과 영상의 대비가 낮아 모서리가 잘 드러나지 않습니다. 어두운 고객 페이지에서와 같은 모습이라 따로 밝히지 않습니다.
  - 미리보기의 플레이어 그림(PlayerMock)은 `--sa-pm-radius`로 프리셋 모서리를 그립니다. "프리셋 모양 그대로" 예(`div.sa-stage-shapes > figure`)가 세 내장 모양을 나란히 보입니다.
- 폭 보기: "좁게 · 390", "보통 · 768", "넓게 · 자리 폭". 처음 값은 넓게입니다.
  - 화면이 `sa-stage-frame`에 `--_w`(그리는 폭 px)와 `--_s`(줄임 비율, 1 이하), `sa-stage-view`에 `--_h`(줄인 높이 = 폭 × 9/16 × 비율)를 넣습니다. 줄임은 `transform: scale`이라 iframe 안 페이지는 고른 폭 그대로 그려집니다(390을 고르면 플레이어의 좁은 화면 규칙이 그대로 보입니다).
  - 비율 글자: "보이는 폭 768px · 실제의 63%로 줄여 보여요", "보이는 폭 390px · 실제 크기예요", "자리 폭 698px · 실제 크기예요". 비율은 정수 %입니다.
  - 자리 폭이 바뀌면(창 크기, 옆 칸 접기) 다시 계산합니다(`ResizeObserver`). 스크립트가 없으면 `--_s`가 1이고 넓게처럼 보입니다.
  - 줄여 보일 때 플레이어 안 글자는 12px보다 작아질 수 있습니다. 실제 크기의 축소 그림이라 디자인 시스템의 글자 하한을 적용하지 않습니다. 비율 글자로 줄였다는 사실을 알립니다.
- 장면 바로가기: "처음부터"(`start`), "미드롤 앞"(`before-midroll`), "끝 직전"(`before-end`). 관리자 미리보기와 재생 오류 때는 "다시 불러오기"(`restart`)를 넷째로 둡니다.
  - 플레이어가 준비되기 전에는 셋 다 `disabled`(잠깐의 막음)이고, 묶음 `aria-describedby`로 "플레이어가 준비되면 쓸 수 있어요."를 잇습니다.
  - 편성에 미드롤이 없으면 "미드롤 앞"만 `aria-disabled="true"`로 막고 이유를 버튼의 `aria-describedby`로 잇습니다. 이유를 Tab으로 와서 들을 수 있어야 해서 `disabled`를 쓰지 않습니다.
  - 누르면 초점은 버튼에 남습니다. 플레이어로 옮기지 않습니다(연달아 눌러 보는 일이 많습니다).
- 최근 광고 진행 한 줄: "프리롤 1/2 재생 중", "미드롤 1/1 · 끝남"처럼 위치(프리롤·미드롤·포스트롤), 순번, 상태를 씁니다. 광고가 없을 때는 "아직 광고가 나오지 않았어요"입니다.
  - 알림 영역(`aria-live`)이 아닙니다. 광고 하나에 여러 번 바뀌어 낭독이 플레이어 소리와 겹칩니다. 데모는 아래 광고 진행 기록(ActivityLog `sa-logbox`)으로 모두 읽을 수 있습니다.
- 샘플 미디어 없음: `sa-stage-view.is-empty`는 점선(`line-2`) 칸에 모서리 `radius-card`, 배경 `panel-2`입니다. 플레이어가 없는 자리라 프리셋과 상관없는 모양으로 그려, 플레이어 모양으로 오해하지 않게 합니다. 안에 `div.sa-empty`(제목 "샘플 미디어가 없어요", 준비 방법 한 줄, 설명서 링크 `a.sa-link`)를 둡니다. 플레이어 자리는 비우고 대체 소재를 만들지 않습니다(명세 2절). 폭 보기는 숨깁니다.
- 상태 문구: 준비 중 "플레이어를 준비하는 중이에요…"(`role=status`), 실패 "플레이어를 만들지 못했어요. 다시 불러오기를 눌러 주세요."(`is-bad`, `role=alert`). 준비되면 문구를 비웁니다.
- 움직임: 폭을 바꿀 때 크기 변화에 전환 효과를 주지 않습니다.
- `a.sa-link`는 이번에 더한 문장 안 링크 클래스입니다(`ink` 글자, `line-2` 밑줄, 마우스를 올리면 밑줄이 글자색).
