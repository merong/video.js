# Storyboard

도움말 용어의 움직임을 2–4장면의 정지 그림으로 나눠 보입니다. 디자인 검토와 도움말 글의 장면 설명에 씁니다. 실제로 움직이는 그림은 HelpMotion(`sa-mo-*`)입니다.

- 구조: `section.sa-sb[aria-labelledby]` > `div.sa-sb-h`(용어 이름 `h3`, 한 줄 설명 `sa-small`) + `ol.sa-sb-scenes > li.sa-sb-scene`. 장면 안은 번호 `sa-sb-n`, 그림 `div.sa-sb-stage[aria-hidden="true"]`, 설명 `p`.
- 그림 칸은 장식입니다. 같은 내용을 설명 문장이 글로 전합니다. 장면이 바뀌어도 화면 읽기 프로그램에 알리지 않습니다(설명이 이미 모두 보이므로).
- 그림 조각: `sa-sb-page`(페이지), `sa-sb-line`(`is-short`), `sa-sb-slot`(자리 요소, `is-filled`는 플레이어가 된 자리), `sa-sb-chip`(`is-mark`는 바뀐 것 한 곳). 플레이어 그림이 필요하면 PlayerMock을 넣습니다.
- 라임 `is-mark`는 한 스토리보드에 한 곳만, 바뀐 것을 가리키는 장면에만 씁니다.
- 장면 칸은 `minmax(160px, 1fr)`로 채워 390에서는 한 줄에 하나씩 쌓입니다.
- HelpMotion으로 옮길 때 시간(**제안**, 캔버스 K): 장면마다 1.2초 보이고 0.3초 동안 다음 장면으로 바뀝니다. 끝 장면에서 2초 쉬고 처음으로 돌아갑니다. 4장면이면 한 바퀴 약 7.7초라 `motion-help-loop`(8초) 안에 듭니다. 움직임 줄이기 설정에서는 마지막 장면만 멈춰서 보입니다. 5초가 넘게 반복하므로 재생·멈춤 버튼을 둡니다.
- 근거: 캔버스 K(도움말 용어 모션 스토리보드).
