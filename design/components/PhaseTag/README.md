# PhaseTag

설명서·도움말의 옵션이 지금 플레이어 화면에 쓰이는지, 저장만 되고 다음 단계에 쓰이는지를 글자로 보입니다.

- 구조: `span.sa-phase`. 쓰이는 값은 `is-live`(실선, `panel-2`)에 "적용", 준비 중인 값은 기본(점선)에 "준비 중(A2-2)" 또는 "준비 중(A2-3)"입니다.
- 단계는 글자로만 알립니다. 색이나 점선만으로 구분하지 않습니다. 화면 읽기 프로그램도 글자 그대로 읽습니다.
- 옵션 표(OptionTable)의 "적용 단계" 칸, 절 전체가 준비 중일 때 절 제목 줄(`sa-doc-hrow`) 옆에 둡니다. 제목 안에 넣지 않습니다(제목 이름에 섞입니다).
- 표 위에는 뜻을 한 번만 적습니다. "준비 중인 값은 저장할 때 검사하지만 플레이어 화면에는 아직 쓰지 않아요. 괄호 안은 그 값을 화면에 쓰기 시작하는 작업 단계예요."
- 단계 나눔(명세 `ads-demo-preview-spec.md` 4절, 스키마 `ads-player-schema-v2.md` 150행): A2-1 적용은 테마, 재생 동작, 표시, 언어, 광고 문구 3개(`skip`·`skipCountdown`·`timer`), `timeouts`입니다. `input`·`controls`는 A2-2, `logo`·`progress`·나머지 광고 문구는 A2-3입니다.
- 목업 화면 표시(MockBadge, "목업 · 아직 동작하지 않아요")와 다릅니다. MockBadge는 화면 전체가 서버와 이어지지 않았을 때, 이 표시는 값 하나가 아직 화면에 쓰이지 않을 때 씁니다.
