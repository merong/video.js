# LabelField

광고 화면 문구 16개를 고치는 칸입니다. 기본 문구는 흐린 자리표시 글자로 보이고, 바꾼 칸에만 "기본값으로" 버튼이 생깁니다.

- 구조: `div.sa-labelfields` 안에 칸마다 `div.sa-labelfield`. 그 안에 Field(`sa-field`)와, 값을 바꿨을 때만 `button.sa-btn.is-sm`("기본값으로")을 둡니다. 버튼에는 `aria-label="광고 순서 문구를 기본값으로"`처럼 칸 이름을 넣습니다.
- 라벨 옆에 문구 키를 `span.sa-key`(고정폭 12px)로 적습니다. 개발자와 운영자가 같은 이름으로 말할 수 있게 하려는 것입니다.
- 비어 있으면 기본 문구를 씁니다. 기본 문구는 `placeholder`로 보이고 **늘 한국어**입니다. 프리셋 언어(플레이어 화면 언어)가 바뀌어도 광고 문구는 바뀌지 않습니다(결정 29).
- 자리표시자(`{index}`, `{count}`, `{seconds}`, `{elapsed}`, `{duration}`, `{remaining}`)는 도움말에 `code.sa-code`로 적고 뜻을 함께 씁니다.
- 서버가 422로 거부하면(모르는 자리표시자 등) `sa-field.is-error`와 `aria-invalid="true"`로 그 칸에 문구를 붙입니다. 예: "{second}는 쓸 수 없는 자리표시자예요. 남은 초는 {seconds}로 고쳐 주세요."
- "기본값으로"를 누르면 값을 비우고 초점을 그 입력 칸으로 돌려놓습니다. 버튼이 사라지므로 초점이 사라지지 않게 하려는 것입니다.
- 줄이 좁으면 버튼이 칸 아래로 내려갑니다(390).
- 근거: 캔버스 G(광고 화면), 명세 결정 29.
