# Progress

보장 집행의 노출 진도를 기대 진도와 함께 보여 주는 막대입니다. 캠페인 목록과 상세의 집행 표에 씁니다.

- 구조: `div.sa-progress` 안에 `div.sa-bar[style="--v:진도;--e:기대"][role=img][aria-label]`와 `<i></i><b></b>`, 아래에 `span.sa-small` 문구.
- 채움은 `primary`, 기대 눈금은 `mark`입니다. 미달로 끝난 집행은 `is-behind`로 채움을 `bad`로 바꿉니다.
- 문구는 "34.1% · 기대 33.2%"처럼 숫자를 함께 적습니다. 대시보드에는 진도 경고를 두지 않습니다.
- 기간제와 하우스처럼 목표가 없는 집행은 막대 대신 "–"를 둡니다.
- 기대 눈금 없이(강의 "학습 진도" 표 같은 곳): `--e`를 비우면 눈금 `<b>`가 숨습니다(`visibility: var(--e, hidden)`). `<b>`를 아예 빼도 됩니다. 이때 문구는 "42%"처럼 진도만 적습니다.
