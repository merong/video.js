# Segmented

값이 몇 개뿐인 선택(±초 버튼, 미리 불러오기, 미리보기 장면)을 붙은 버튼 모양으로 보입니다. 속은 네이티브 라디오 묶음입니다.

- 구조: `div.sa-seg[role=radiogroup][aria-labelledby]` 안에 `label > input[type=radio][name]` 를 값마다 둡니다. 라벨 이름은 바깥 `span.sa-label[id]`이고, 도움말은 `aria-describedby`로 연결합니다.
- 키보드: Tab으로 묶음에 들어오면 고른 값에 초점이 갑니다. 왼쪽·오른쪽(위·아래) 방향키로 옮기면 바로 골라집니다. 브라우저 라디오 기본 동작이라 스크립트를 쓰지 않습니다.
- 고른 값은 `primary` 채움, 초점은 `focus-ring`을 칸 밖에 그립니다. 숫자 값 묶음에는 `is-num`을 붙여 Inter로 씁니다.
- 기본값은 라벨 글자에 "(기본)"을 붙여 알립니다. 색이나 굵기만으로 알리지 않습니다.
- 칸이 넘치면 다음 줄로 내려갑니다(390). 가로 스크롤을 만들지 않습니다.
- 값이 다섯 개를 넘거나 설명이 길면 Select를 씁니다.
- ThemePreview의 "본편 · 광고 중" 장면 고르기도 이 부품입니다. 장면 고르기는 미리보기만 바꾸고 저장 값이 아닙니다.
- ±초 버튼은 A2-E부터 SwitchList의 "이전·이후 버튼" 스위치와 딸린 칸의 이 묶음("건너뛰는 폭", 5초 · 10초 · 15초 · 30초)으로 나눕니다. "숨김"은 스위치가 맡으므로 묶음에 넣지 않습니다. 위 미리보기의 "숨김 (기본)" 묶음은 예전 모양입니다.
- 근거: 캔버스 D(±초 버튼), E(미리 불러오기), H(테마 미리보기).
