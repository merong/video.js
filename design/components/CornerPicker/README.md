# CornerPicker

로고 위치를 플레이어 모양 안 네 모서리에서 고릅니다.

- 구조: `fieldset.sa-corner > legend.sa-label` 아래 `div.sa-corner-frame`에 `label > input[type=radio][name]` 4개를 둡니다. 순서는 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래이고 값은 `top-left`, `top-right`, `bottom-left`, `bottom-right`입니다. 기본은 오른쪽 위입니다.
- 키보드: 방향키는 DOM 순서(왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래)로 옮깁니다. 위·아래 키가 화면에서 위아래로 가지 않는 점은 도움말 "방향키로 모서리를 옮겨 고를 수 있어요."로 알리고, 지금 고른 모서리 이름을 도움말에 글로 적습니다.
- 라벨 글자("왼쪽 위" 등)는 늘 보입니다. 모서리 위치만으로 뜻을 전하지 않습니다.
- 틀은 `dark` 바탕입니다. 먹색 초점선이 보이지 않으므로 이 틀 안에서만 초점선을 `accent`(라임)로 그립니다. 고른 칸은 실선 테두리와 `on-dark` 글자로 바뀝니다.
- 틀 폭은 280px이고 부모보다 넓어지지 않습니다(`max-width: 100%`).
- 쓸 수 없을 때는 `fieldset`에 `disabled`를 걸면 네 라디오가 함께 막히고 틀이 흐려집니다.
- 근거: 캔버스 C(로고), B 390.
