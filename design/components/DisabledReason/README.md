# DisabledReason

기본 video(`native`) 프리셋에서 쓸 수 없는 구획이나 스위치에 이유와 바꾸는 방법을 붙입니다.

- 구조: 구획 머리 아래 `p.sa-off-reason[id]`, 막힌 내용은 `div.sa-off-body`로 감쌉니다. 막힌 칸마다 `aria-describedby`로 이유 문장을 연결합니다.
- 문구는 "무엇을 쓸 수 없는지 · 왜 · 어떻게 바꾸는지" 순서입니다. 예: "<b>기본 video에서는 로고를 쓸 수 없어요.</b> 기본 구획의 플레이어 종류를 Video.js로 바꾸면 쓸 수 있어요."
- 입력한 값은 지우지 않고 화면에 그대로 둡니다. 저장할 때 서버로 `null`을 보내고, 저장 전에 Video.js로 되돌리면 값이 살아 있습니다(결정 27). 그래서 몸통은 `opacity`로만 흐리게 하고 값은 읽을 수 있게 둡니다.
- 칸은 `disabled`로 막습니다. 스위치 하나만 막을 때는 SwitchList 행에 `is-locked`를 붙이고 같은 이유 문장을 연결합니다.
- 동작 버튼과 링크 버튼은 `disabled`가 아니라 `aria-disabled="true"`로 막아 초점을 받게 둡니다. Tab으로 와서 이유를 들을 수 있어야 하기 때문입니다. 모양과 마크업은 Button의 "초점을 받는 비활성"을 따릅니다. 입력 칸은 구획 머리의 이유 문장을 먼저 지나기 때문에 위처럼 `disabled`로 둡니다.
- 묶음의 일부만 막을 때(A2-E 데모 로고 묶음): 막는 조건이 되는 칸(로고 이미지)은 이유 위에 그대로 두고, 그 아래 칸들을 `div.sa-optgrp-body`로 묶어 막을 때만 `sa-off-body`를 붙입니다. 이유 문장은 "무엇을 하면 쓸 수 있는지"를 먼저 적습니다.
- 구획 전체를 숨기지 않습니다. 사용자가 SectionNav로 옮겨 와서 이유를 읽을 수 있어야 합니다.
- 근거: 캔버스 B(기본 video 종류), E(재생 동작), 명세 결정 27.
