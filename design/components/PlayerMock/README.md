# PlayerMock

관리자 미리보기와 도움말에 쓰는 플레이어 그림입니다. 실제 플레이어가 아니고 눌러지지도 않습니다. 실제 플레이어 화면(±초 버튼, 로고 자리, 광고 진행 막대)은 플레이어 스킨의 일이라 `design/` 밖에 있습니다. 값은 `.agents/plans/ads-player-design-handoff.md`를 봅니다.

- 구조: `div.sa-pm[role=img][aria-label]` 한 장. 안의 조각은 모두 장식이므로 `aria-label`에 그림이 보여 주는 것을 문장으로 적습니다. 예: "본편 장면: 오른쪽 위 로고, ±10초 버튼이 있는 컨트롤".
- 폭: 기본은 부모 폭(`width: 100%`, 16:9). `is-640`·`is-360`은 실제 플레이어 폭을 그릴 때 쓰고, 부모보다 넓어지지 않습니다.
- 조각
  - `sa-pm-scene`: 영상 그림 자리.
  - `sa-pm-title`: 제목(넘치면 말줄임).
  - `sa-pm-logo.is-tl|is-tr|is-bl|is-br`: 로고. 여백은 `--_m`(기본 12px), 아래쪽 모서리는 컨트롤 막대 위로 올라갑니다.
  - `sa-pm-ctl > .sa-pm-row`: 컨트롤 막대. `sa-pm-btn`(아이콘, ±초 버튼은 아이콘 옆 숫자 `sa-pm-n`), `sa-pm-track > b`(진행, `--_p`로 길이), `sa-pm-time`, `sa-pm-sp`(빈 칸).
  - 광고 중: `sa-pm-badge`("광고 1/2"), `sa-pm-adfoot`(시간 문구, `sa-pm-skip`), `sa-pm-adbar > b`(진행 막대 3px).
  - `is-hidectl`: 컨트롤이 숨은 상태. 아래쪽 로고는 모서리(여백만큼)로 내려옵니다.
- 모서리: `--sa-pm-radius`(기본 `radius-card`)로 프리셋 모서리를 그립니다. 예: 기본 스킨 `28px`, 플랫 `0`, 둥근 테두리 `12px`. 무대(PlayerStage)가 모서리를 더하지 않으므로 이 값이 그대로 보입니다(A2-E).
- 색은 `dark` 계열 토큰만 씁니다. 광고 강조색은 `--sa-pm-accent`로 바꿔 그립니다. 비우면 테마 강조색(`accent`)입니다. 이 값은 미리보기 그림용이고, 플레이어의 실제 색은 `ads.accentColor`입니다.
- 360에서는 여백이 줄고 ±초 숫자가 감춰져 아이콘만 남습니다. PiP는 기본 스킨 동작 그대로라 360에서도 컨트롤 막대에 있습니다(결정 25).
- 12px보다 작은 글자를 쓰지 않습니다.
- 그림 안 아이콘은 플레이어 크기(640 20px, 360 16px)를 따릅니다. 관리자 화면 아이콘 규칙(16px)과 다릅니다.
- 근거: 캔버스 B(미리보기), H(테마 미리보기), I(플레이어 화면).

## 자막 없음 (A2-E, 사실 기록)

실제 플레이어의 일이라 `design/` 밖(광고 전용 스킨 `solad-video-skin`)에서 만듭니다. 명세 3.2의 사실만 적습니다.

- `controls.captions`가 켜져 있고 영상에 자막·캡션 트랙이 없으면 자막 버튼을 보이되 막습니다(`aria-disabled="true"`, 초점은 받음). 눌러도, 단축키 `c`를 눌러도 아무 일이 없습니다.
- 버튼 이름과 툴팁은 플레이어 화면 언어를 따릅니다: ko "자막 없음", en "No captions", ja "字幕なし", zh-CN "无字幕".
- `controls.captions`가 꺼져 있으면 자막 버튼, 설정 메뉴의 자막 항목, 단축키 `c`가 모두 없고 Tab 순서에도 남지 않습니다.
- 좁은 폭에서 기본 스킨이 자막 버튼을 숨기는 규칙은 그대로입니다.
- 이 그림(PlayerMock)은 바꾸지 않습니다. 지금 그림의 컨트롤 막대에는 자막 버튼이 없고, 장식 그림에 막힌 버튼 모양을 새로 그리면 스킨이 정할 실제 모양(색·투명도)을 디자인 시스템이 앞서 정한 것처럼 읽히기 때문입니다. 실제 모양은 스킨 구현을 따르고, 확인은 데모 무대에서 합니다.

## 강의 층 (L)

편집기·대화상자 미리보기에서 강의 프리셋의 진도 줄과 한계 표시를 그립니다(명세 5.1). 값은 `.agents/plans/ads-lms-design-handoff.md` 1.5절의 그림판입니다.

- `i.sa-pm-watched`: 시청 구간. `sa-pm-track` 안, 채움 `b`보다 **앞**에 둡니다. 구간마다 하나씩, `--_s`(시작 %)와 `--_w`(길이 %)로 자리를 줍니다. 색은 `--sa-pm-accent` 65%입니다.
- `i.sa-pm-limit`: 한계 표시(세로 2×12px, `on-dark` + 어두운 테두리). `sa-pm-track` 안 맨 뒤에 두고 `--_l`(%)로 자리를 줍니다. 채움과 썸보다 위입니다.
- `p.sa-pm-lms`: 그림 **바로 아래** 진도 줄(그림 밖, `sa-pm`은 넘침을 자르므로). `<b>진도 42%</b><span>완료 기준 90%</span><span class="sa-pm-lms-bar" style="--_p: 42%; --_t: 90%"><i></i><b></b></span>`. 그림과 같은 폭 수식어(`is-640`·`is-360`)를 붙입니다. 강조색은 그림과 같게 `--sa-pm-accent`를 같이 줍니다.
- 진도 줄 채움에는 안쪽 선이 있어 밝은 강조색(라임, 흰색)도 밝은 바탕에서 보입니다. 완료 기준 눈금은 `ink`입니다.
- 미리보기는 저장하지 않으므로 값은 고정 그림입니다(진도 42%, 한계 35%, 시청 0–34%·52–58%). `aria-label`에 "시청한 구간과 한계 표시, 진도 42%"처럼 적고, 진도 줄은 그림의 일부라 따로 읽히지 않게 그림 설명에 넣습니다.
