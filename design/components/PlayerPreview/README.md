# PlayerPreview

관리자 화면의 플레이어 미리보기 칸입니다. 프리셋 편집기의 미리보기(예전 ThemePreview)와 지면 편성의 게시 전 미리보기가 같은 틀을 씁니다. 안의 플레이어는 `examples/preview.html` iframe이고, 관리자 문서에는 로더나 스킨을 불러오지 않습니다(명세 6절).

## 틀

- `section.sa-ppv.sa-card[aria-labelledby]` 안에 차례로
  1. `div.sa-ppv-h`: 제목(`sa-card-title`) + 오른쪽 한 줄 `sa-small`.
  2. (게시 전 미리보기만) "적용할 프리셋" Field.
  3. 상태 문구 `p.sa-status`.
  4. PlayerStage(`div.sa-stage`): 폭 보기, 무대(`iframe`), 장면 바로가기 + "다시 불러오기", 최근 광고 진행 한 줄.
  5. (편집기, 언어가 비었을 때만) "페이지 언어" Field.
  6. (편집기만) `div.sa-ppv-f`: "데모에서 열기".
- iframe: `iframe[title="플레이어 미리보기 화면"]`, 주소 `preview.html?type=videojs|native`. 폭 보기는 iframe 폭(`--_w`)을 바꾸고 `scale`로 줄입니다. 그래서 iframe 안은 고른 폭의 화면 규칙 그대로입니다.
- 1280 편집기에서는 편집 칸 오른쪽 열(약 460px)에 붙고, 768·390에서는 편집 칸 아래로 내려갑니다(배치는 화면이 정합니다). 미리보기 칸을 접는 버튼은 예전 ThemePreview와 같습니다.

## 프리셋 편집기

- 제목 "플레이어 미리보기", 오른쪽 "저장하기 전 입력도 보여요".
- 페이지 언어: 프리셋의 플레이어 화면 언어가 비었을 때만 보입니다. 선택지는 한국어 (ko), 영어 (en), 일본어 (ja), 중국어 간체 (zh-CN), 그 밖의 언어 (fr). 도움말 "플레이어 화면 언어를 비워서 페이지 lang을 따라요. 미리보기에서만 바꿔 보고 저장하지 않아요." 언어를 정하면 칸이 사라지고, 다시 비우면 마지막 고른 값으로 돌아옵니다.
- 데모에서 열기
  - 저장된 프리셋: `a.sa-btn[target=_blank]`(아이콘 + "데모에서 열기" + `sa-sr` " (새 창)"). 주소는 `examples/index.html?preset=<id>`.
  - 저장하지 않은 입력이 있음: `button.sa-btn[aria-disabled="true"]`(초점은 받고 누를 수 없음, Button의 "초점을 받는 비활성")를 `span.sa-btn-why`로 감싸고 "저장하지 않은 입력이 있어요. 저장하면 데모에서 열 수 있어요."를 `aria-describedby`로 잇습니다.
  - 새 프리셋(아직 id 없음): 같은 꼴로 "새 프리셋은 저장한 뒤 데모에서 열 수 있어요."
  - 링크와 버튼이 바뀌어도 자리와 글자는 같습니다. 저장 직후 초점은 저장 버튼에 남습니다.

## 지면 편성 게시 전 미리보기

- 제목 "게시 전 미리보기", 오른쪽 "통계에 남기지 않아요".
- 무대 위에 "적용할 프리셋" select가 옵니다(편집기의 페이지 언어 자리 대신). 처음 값은 사이트 적용 프리셋이고 이름 뒤에 " (사이트 적용)"을 붙입니다. 도움말 "고른 프리셋 모양으로 이 초안을 재생해요. 편성에는 저장되지 않아요."
- 프리셋을 바꾸면 미리보기를 다시 만듭니다. 고른 프리셋은 편성에 저장하지 않습니다.
- "데모에서 열기"는 두지 않습니다(초안은 데모에서 열 수 없습니다). 고른 프리셋의 언어가 비었으면 페이지 언어 칸은 편집기와 같은 규칙으로 아래에 보입니다.

## 상태 문구 (프레임 `ads-player-preview-status`)

| status | 문구 | 꼴 |
| --- | --- | --- |
| `loading` | 미리보기를 준비하는 중이에요… | `sa-status`, `role=status` |
| `ready` | (비움) | — |
| `missing-sample` | 샘플 미디어가 없어 미리보기를 재생할 수 없어요. 서버에 demo-media/grok-20261018/ 폴더를 넣어 주세요. | `is-warn`, `role=status` |
| `error` | 미리보기를 만들지 못했어요. 다시 불러오기를 눌러 주세요. | `is-bad`, `role=alert` |

- 프레임이 보낸 `message`는 화면에 그대로 넣지 않습니다. 위 문구를 씁니다(관리자 화면은 해요체, 문구표가 원본).
- 준비되기 전에는 장면 바로가기 셋을 막습니다("다시 불러오기"는 늘 됩니다). 이유는 PlayerStage 규칙과 같습니다.

## 최근 광고 진행 한 줄

- `ads-player-preview-event`의 `{kind, position}`를 "프리롤 1/2 재생 중", "미드롤 1/1 · 끝남"처럼 씁니다. 처음에는 "아직 광고가 나오지 않았어요"입니다. 알림 영역이 아닙니다.

## 프리셋 목록 미리보기 대화상자 (A2-E)

목록(`#/players`)의 "미리보기" 버튼이 여는 모달입니다. 틀은 Dialog의 넓은 변형(`dialog.sa-dialog.is-wide`)이고, 본문은 이 칸과 같은 플레이어 미리보기입니다. 마크업과 폭은 Dialog README "플레이어 미리보기 (A2-E)"를 봅니다.

- 제목은 대화상자 머리의 "<이름> 미리보기"가 맡으므로 `sa-ppv-h`와 카드(`sa-card`)를 쓰지 않습니다. "저장된 값 · 통계에 남기지 않아요"는 대화상자 머리의 제목 옆에 둡니다. 본문에 차례로 (저장하지 않은 입력이 있을 때) Note, 상태 문구, PlayerStage(폭 보기, 무대, 장면 바로가기 + "다시 불러오기", 최근 광고 진행), (언어가 비었을 때) "페이지 언어" Field를 둡니다.
- 늘 저장된 값으로 재생합니다(`demo={{presetId, unsaved:false}}`). 그래서 "데모에서 열기"는 막지 않고 바닥줄 왼쪽에 둡니다.
- 처음 폭 보기는 "넓게 · 자리 폭"입니다. 1280×800에서 자리 폭은 702px이고, 본문 높이가 모자라면 높이에 맞춰 640px·551px로 줄입니다(Dialog README "플레이어 미리보기 (A2-E)").
- 닫으면 iframe을 지워 소리가 남지 않게 하고, 다시 열면 처음부터 만듭니다.
