# UnimplementedCard

메뉴는 있지만 아직 만들지 않은 화면 자리에 두는 카드입니다. 무엇을 하는 화면인지와 기획 문서 위치를 적어 빈 화면으로 두지 않습니다.

- 클래스: `sa-card is-unbuilt`(점선 테두리) 안에 `sa-card-title`, 설명 `sa-body`, 문서 경로 `sa-code`를 넣습니다.
- 화면 전체가 아직 없을 때(승인함, 설정, 집행 만들기)는 다른 목업 화면처럼 페이지 제목 옆에 MockBadge를 두고 이 카드를 그 아래에 놓습니다. 메뉴에 없고 머리 오른쪽 버튼으로 여는 화면도 같습니다.
- 표 안에서 결과가 없을 때는 `td.sa-empty`(colspan 전체)에 `b` 한 줄과 다음 할 일을 적습니다. 예: "조건에 맞는 요청이 없어요" + "필터를 바꿔 보세요."
