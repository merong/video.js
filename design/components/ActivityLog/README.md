# ActivityLog

요청·집행에 누가 언제 무엇을 했는지 최신 순으로 보여 주는 처리 기록입니다.

- 클래스: `ol.sa-log`, 각 줄은 `li` 안에 `time.sa-num`(시각)과 `span`(한 일)입니다. `time`에는 `datetime`을 넣습니다.
- 시각 칸은 92px로 고정합니다. 문장은 "admin이 검토를 시작했어요."처럼 주어와 한 일을 함께 적습니다.
- 알림 실패처럼 확인이 필요한 기록도 지우지 않고 그대로 남깁니다.

## 광고 진행 기록 (A2-D)

데모와 재생 테스트의 광고 진행 기록도 이 목록을 씁니다.

- `div.sa-logbox[role=region][aria-labelledby=<카드 제목>][tabindex=0]` 안에 `ol.sa-log`를 둡니다. 상자는 최대 320px이고 넘치면 안에서 세로로 스크롤합니다. 키보드로 들어가 화살표로 움직일 수 있게 `tabindex=0`입니다.
- 한 줄은 `time.sa-num`(시:분:초) + "<위치> <순번>/<개수> · <일>"입니다. 예: "미드롤 1/2 · 시작". 위치는 프리롤·미드롤·포스트롤, 일은 시작·끝남·건너뜀·클릭·오류·중단입니다. 주어가 플레이어라 "누가"를 쓰지 않습니다.
- 최근 20개만 두고 새것이 위입니다. 비었으면 상자 안에 `sa-empty`("아직 광고 진행이 없어요" + "재생하면 여기에 쌓여요.")를 둡니다.
- 알림 영역(`aria-live`)이 아닙니다. 광고 하나에 기록이 여러 개 생겨 낭독이 플레이어 소리와 겹칩니다.
- 처리 기록(관리자)과 달리 지워도 됩니다. 데모는 "기록 지우기" 버튼을 둡니다.
