# StatusMessage

저장, 승인, 불러오기처럼 방금 한 일의 결과를 알리는 문구입니다. 화면 읽기 프로그램이 바로 읽도록 `aria-live` 영역을 씁니다.

- 클래스: `sa-status`, 종류 `is-good`(완료) / `is-warn`(일부만 됨) / `is-bad`(실패).
- 성공·안내는 `role="status"`(`aria-live="polite"`), 실패는 `role="alert"`를 씁니다.
- 영역은 처음부터 화면에 두고 글자만 바꿉니다. 비어 있으면 `:empty`로 화면에서만 감추고 접근성 트리에는 남깁니다(`display: none`을 쓰면 첫 문구가 읽히지 않을 수 있어요).
- 실패 문구에는 무엇이 안 됐는지와 다음 할 일을 함께 적습니다. 예: "저장하지 못했어요. 잠시 뒤 다시 저장해 주세요."
