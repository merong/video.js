# DataTable

목록과 집행 라인을 보여 주는 표입니다. 기본과 밀집 두 밀도가 있습니다.

- 구조: `div.sa-card.is-flush` 안에 선택적으로 `div.sa-toolbar`, 그 아래 `div.sa-scroll > table.sa-table`.
- 숫자 칸은 `td.num`(오른쪽 정렬, Inter, tabular-nums)입니다. 머리 칸도 `th.num`으로 맞춥니다.
- 이름 칸은 `div.sa-name` 안에 `<b>` 이름과 `<small>` 보조 줄(ID, 수정본, 일시중지 시각)을 둡니다.
- 선택된 행은 `tr.is-selected`(`accent-soft`), 합계는 `tfoot`(`panel-2`, 700)입니다.
- 밀집은 카드에 `sa-dense`를 붙입니다. 행 `row-h-dense` 36px, 셀 12.5px, 숫자 12px, 툴바 컨트롤 30·26px이 됩니다. 승인함, 캠페인 상세의 집행 표, 지면 편성 목록, 소재 목록에만 씁니다.
- 좁은 화면에서는 표가 `sa-scroll` 안에서 가로로 넘어갑니다. 열을 숨기지 않습니다.
- `sa-scroll`은 `position: relative`입니다. 그래서 숨긴 caption과 머리글의 `sa-sr`(절대 위치)도 이 스크롤 안에 갇히고 페이지 폭을 늘리지 않습니다. 표를 감싸는 가로 스크롤 영역을 따로 만들 때도 `position`을 둡니다. 없으면 390px 화면에서 페이지가 표 폭만큼 넓어집니다.
- 행마다 "열기" 같은 동작 버튼이 있으면 마지막 열의 `th`와 `td`에 `is-pinned`를 붙입니다. 표가 넘쳐도 그 열은 카드 오른쪽 끝에 붙어 있고, 나머지 열이 그 아래로 지나갑니다. 마지막 열에만 씁니다. React는 `DataTableColumn.pinEnd`입니다.
- 표 위 설명은 `caption`으로 넣어 표 이름을 정합니다. 화면에 보일 필요가 없으면 툴바 제목을 `aria-labelledby`로 잇습니다.
- 행이 없으면 `tbody` 안에 `td.sa-empty[colspan]` 한 칸을 두고 `<b>` 한 줄과 다음 할 일을 적습니다.

## 플레이어 프리셋 표 (A2)

새 CSS 없이 기존 표 부품으로 만듭니다.

- 열은 이름, 플레이어 종류, 사이트 적용, 바꾼 날, 동작입니다. 예전 "스킨" 열은 뺍니다(스킨 선택이 없어졌으므로).
- "사이트 적용" 열에는 적용된 한 행에만 StatusBadge `is-site`를 둡니다. 다른 행은 빈 칸으로 두고 `sa-sr`로 "아님"을 넣지 않습니다(표 머리가 이미 뜻을 줍니다).
- 동작 열(`is-pinned`)에 "편집"과 "사이트에 적용"을 둡니다. 이미 적용된 행의 "사이트에 적용"은 `aria-disabled="true"`로 막고(Button의 "초점을 받는 비활성") `span.sa-btn-why` 안에 이유 "지금 적용된 프리셋이에요"를 `sa-small`로 붙여 버튼의 `aria-describedby`로 잇습니다.
- "사이트에 적용"은 바로 바꾸지 않고 확인 Dialog(사이트에 적용 확인)를 엽니다.
- "미리보기"(A2-E)는 동작 칸 맨 앞에 둡니다. 순서는 미리보기 · 편집 · 사이트에 적용입니다. 보이는 글자는 "미리보기", 이름은 `aria-label` "<이름> 미리보기"입니다(보이는 글자를 이름 안에 그대로 넣습니다). 누르면 Dialog의 플레이어 미리보기(`sa-dialog.is-wide`)가 열립니다. 내장 프리셋 행에도 둡니다.
  - 자리를 고른 이유: 화면을 바꾸지 않는 가장 가벼운 동작이라 앞에, 되돌리기 어려운 "사이트에 적용"이 끝에 오게 했습니다. 고정 열이라 좁은 폭에서도 표를 넘기지 않고 누를 수 있습니다.
  - 좁은 폭: 동작 칸은 390에서 지금처럼 약 160px이고, 버튼이 두 줄로 접힙니다(미리보기 · 편집 / 사이트에 적용). 이름 칸은 왼쪽에 그대로 보입니다. 768에서는 한 줄(약 270px), 1280에서는 한 줄입니다.
