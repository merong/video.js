# SubNav

한 메뉴 안의 화면을 오가는 링크 줄입니다. 플레이어 메뉴의 프리셋 · 초기 설정 방법 · 옵션 설명처럼 주소가 바뀌는 하위 화면에 씁니다.

- 구조: `nav.sa-subnav[aria-label]` > `a[href]`. 현재 화면 링크에 `aria-current="page"`를 붙입니다. 화면 제목 바로 아래, 본문 카드 위에 둡니다.
- 링크가 없는 하위 화면(프리셋 편집, 새 프리셋)에서는 링크를 더하지 않고 그 화면이 속한 "프리셋 목록"을 현재로 둡니다. 어느 화면인지는 아래 `h2` 제목이 알립니다.
- ARIA 탭이 아닙니다. `role=tablist`·`tab`을 쓰지 않고, 화살표 키 이동도 없습니다. Tab으로 링크를 차례로 지나고 Enter로 이동합니다. 주소가 바뀌므로 새로 고침해도 같은 화면이고 새 탭으로 열 수도 있습니다.
- 현재 항목은 굵은 `ink` 글자와 아래 2px `primary` 밑줄입니다(어두운 테마에서는 라임). 나머지는 `sub` 글자입니다. 바닥에 `line` 한 줄을 깝니다.
- 좁은 화면에서는 줄이 가로로 스크롤됩니다. 초점 링은 잘리지 않게 링크 안쪽에 그립니다.
- 상단 메뉴(`TopNav`)는 앱 전체 메뉴, 링크 칩(`ChipNav`)은 같은 목록의 상태 필터입니다. 서로 다른 화면 사이를 오갈 때만 SubNav를 씁니다.
