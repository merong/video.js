# TopNav

가로 주 메뉴입니다. 높이는 `nav-h`(52px), 바탕은 `panel`입니다. 관리자 화면 틀은 왼쪽 메뉴(SideNav)를 쓰고, 이 메뉴는 로그인 화면처럼 메뉴가 없는 머리줄과 문서 화면에 씁니다.

- 메뉴는 대시보드, 캠페인, 소재, 지면 편성, 승인함, 리포트, 설정 순서입니다. 현재 화면은 `aria-current="page"`로 `primary` 채움을 받습니다.
- 승인함 대기 건수는 라임 `<b>`로 붙입니다.
- 오른쪽에는 검색, 화면당 하나의 라임 버튼(집행 만들기), 사용자 표시를 둡니다.
- 로고는 "솔애드" 글자(800)와 라임 "관리자" 태그입니다. 구조: `span.sa-logo` 안에 `솔애드 <em>관리자</em>`.
- 그누보드 팝업은 로고 자리에 `[사이트 이름] <em>광고 관리</em>`를 쓰고, 오른쪽에 사이트 보기 · 관리자 표시 · 창 닫기를 둡니다. 창 닫기는 `window.opener`가 있을 때만 보입니다.
- 960px 미만에서는 메뉴가 두 번째 줄로 내려가 가로로 넘어가고, 검색은 숨습니다. 로고와 오른쪽 동작은 첫 줄에 남습니다.
