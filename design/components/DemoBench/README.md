# DemoBench

플레이어 데모(`examples/index.html`) 화면입니다. 프리셋을 고르고 설정 옵션을 바꿔 보며 플레이어를 확인하고, 그 상태의 설치 코드를 복사합니다. 저장하지 않습니다(명세 3절).

## 틀

- 위쪽 탐색은 DocShell과 같고 "데모"가 현재입니다. 목차는 두지 않습니다.
- `main.sa-bench` 안 다섯 구역. 읽는 순서와 DOM 순서가 같습니다.
  | 구역 | 클래스 | 1280 | 960 이하 |
  | --- | --- | --- | --- |
  | 프리셋 줄 | `sa-bench-pick` | 맨 위 한 줄 | 맨 위 |
  | 플레이어 | `sa-bench-stage` (PlayerStage) | 가운데 왼쪽 | 둘째 |
  | 설정 옵션 | `sa-bench-opts` | 가운데 오른쪽 360px | 셋째 |
  | 설치 코드 | `sa-bench-code` | 아래 왼쪽 | 넷째 |
  | 광고 진행 기록 | `sa-bench-log` | 아래 오른쪽 360px | 다섯째 |
- 화면을 보기 좋게 하려고 `order`나 영역 배치로 순서를 바꾸지 않습니다. 키보드 순서가 보이는 순서와 같아야 합니다.

## 프리셋 줄

- `div.sa-doc-head`(제목 "플레이어 데모"와 한 문장 소개), 프리셋 Field, 되돌리기 묶음(`sa-bench-reset`).
- 프리셋은 `select.sa-input` 하나입니다. 묶음은 `optgroup`입니다.
  - 로그인하지 않음: 첫 항목 "사이트 적용 프리셋"(묶음 없음) + `optgroup "내장"`(기본, 플랫, 둥근 테두리, 강조색. 이 순서로 넷). 도움말 "관리자로 로그인하면 저장 프리셋도 고를 수 있어요."
  - 로그인함: `optgroup "내장"` + `optgroup "저장 프리셋"`. 사이트 적용 프리셋은 이름 뒤에 " (사이트 적용)"을 붙입니다. 내장 프리셋이 사이트 적용이면 내장 묶음에서 붙습니다. 도움말 "관리자로 로그인해 있어서 저장 프리셋도 보여요."
  - 목록 오류(401·403 밖): Field `is-warn`, 도움말 자리에 "저장 프리셋 목록을 불러오지 못했어요. 내장 프리셋과 사이트 적용 프리셋만 보여요. 새로고침하면 다시 불러와요." 401·403은 조용히 로그인하지 않음과 같게 보입니다.
  - 처음 선택: `?preset=`이 있으면 그 프리셋, 없으면 사이트 적용 프리셋.
- 되돌리기: `span.sa-small[id]` "프리셋과 다른 값 N개" + 기본 버튼 "프리셋 값으로 되돌리기"(`aria-describedby`로 잇습니다). 다른 값이 없으면 버튼을 `disabled`로 두고 글자는 "프리셋 값 그대로예요"입니다. 누르면 설정 옵션이 프리셋 값으로 돌아가고 초점은 버튼에 남습니다.
- 잘못된 주소 쿼리: 프리셋 줄 맨 위(제목 아래)에 Note `is-warn` 한 줄. "<b>주소의 값 N개를 무시했어요.</b> preset=old-1, lang=fr · 지금은 프리셋 값으로 보여요." 무시한 값만 적고 닫기 버튼은 두지 않습니다(다음 주소 갱신 때 사라집니다).

## 플레이어

- PlayerStage를 카드(`sa-stage.sa-card`)로 씁니다. 제목 "플레이어", 상태 문구, 폭 보기, 무대, 장면 바로가기, 최근 광고 진행 한 줄.
- 샘플 미디어가 없으면 PlayerStage의 빈 상태를 보이고, 설정 옵션은 그대로 바꿀 수 있습니다(설치 코드는 계속 바뀝니다).

## 설정 옵션

- 카드 제목 "설정 옵션", 아래 한 줄 "저장하지 않아요. 바꾸면 플레이어를 다시 만들어요." + "옵션 설명 보기" 링크(`help.html#attributes`).
- 묶음은 `fieldset.sa-optgrp > legend`입니다. 순서는 재생 동작 · 표시 · 컨트롤 · 로고 · 언어 · 미디어입니다(컨트롤과 로고는 A2-E). 로고 묶음은 아래 "로고 묶음" 절에 따로 적습니다.
  - 재생 동작: SwitchList(자동재생, 음소거, 반복) + Segmented 미리 불러오기(누를 때 / 정보만 / 미리 받기).
  - 자동재생을 켜면 음소거 행에 `is-locked`, 스위치는 켜진 채 `disabled`, 설명이 "자동재생을 켜면 음소거로 시작해요. 브라우저가 소리 나는 자동재생을 막기 때문이에요."로 바뀝니다(로더 규칙과 같습니다).
  - 표시: Check "포스터 보이기" + 포스터 주소, Check "제목 보이기" + 제목, 썸네일 VTT 주소.
  - 컨트롤(A2-E, 명세 3.4): SwitchList 두 줄과 자막 주소 Field.
    - "이전·이후 버튼" 스위치(`controls.seekButtons`). 켜면 같은 줄 아래 딸린 칸 `div.sa-field.sa-switch-sub`에 Segmented "건너뛰는 폭"(5초 · 10초 · 15초 · 30초, `is-num`)이 나옵니다. 처음 켜면 10초이고, 같은 화면에서 껐다 다시 켜면 마지막에 고른 값으로 돌아옵니다. 끄면 딸린 칸을 `hidden`으로 숨기고 값은 `null`입니다. 스위치에 `aria-controls`로 딸린 칸을 잇습니다.
    - "자막" 스위치(`controls.captions`, 기본 켬). 설명 "자막 버튼과 설정 메뉴의 자막 항목이에요. 영상에 자막이 없으면 버튼이 ‘자막 없음’으로 막혀 보여요.", 단축키 줄 "끄면 단축키 c도 꺼져요."
    - "자막 VTT 주소" Field(`data-captions`). 도움말 "비우면 자막이 없어요. 설치 코드에는 data-captions로 들어가요." 주소 규칙과 오류 문구는 썸네일 VTT 주소와 같습니다.
    - 손쉬운 채우기: 칸 아래 작은 버튼 "샘플 자막 쓰기" + 옆 글자 "한국어 샘플 자막 주소를 채워요."(버튼의 `aria-describedby`). 누르면 데모 페이지와 같은 폴더의 `sample-captions.vtt`를 `/`로 시작하는 경로로 칸에 채웁니다(서버 루트가 `public/`이면 `/examples/sample-captions.vtt`). 경로는 페이지 주소에서 계산하고 문구에 고정 경로를 쓰지 않습니다. 초점은 버튼에 남고, 칸이 바뀌었으니 플레이어를 다시 만듭니다.
    - 자막 스위치를 끄고 주소를 넣어도 됩니다. 주소는 설치 속성이고 스위치는 프리셋 값이라 서로 막지 않습니다(설치 코드에는 둘 다 지금 값대로 들어갑니다).
  - 언어: 플레이어 화면 언어 select("비움 · 페이지 언어를 따름", 한국어 (ko), 영어 (en), 일본어 (ja), 중국어 간체 (zh-CN)). 비움일 때만 "페이지 언어" select가 보입니다. 페이지 언어에는 네 언어와 "그 밖의 언어 (fr)"가 있어 영어로 떨어지는 경우를 볼 수 있습니다.
  - 미디어: Segmented 본편 형식(MP4 / HLS), HLS일 때만 HLS 엔진(Video.js 자체(SPF) / hls.js).
- 기본 video 프리셋을 고르면 제목·썸네일 칸을 DisabledReason으로 막고, 컨트롤 묶음 전체도 DisabledReason으로 막습니다(이유 "<b>기본 video 프리셋에서는 이전·이후 버튼과 자막을 쓸 수 없어요.</b> Video.js 프리셋을 고르면 쓸 수 있어요.", 스위치는 `is-locked` + `disabled`, 주소 칸은 `disabled`, 값은 그대로). HLS 라디오는 `disabled` + 도움말 "기본 video는 HLS를 재생하지 못해요. Video.js 프리셋을 고르면 쓸 수 있어요."입니다. 값은 지우지 않습니다.
- 기본 video 프리셋이면 로고 묶음도 전체를 막습니다("로고 묶음" 절).
- 바꾼 값마다 따로 표시하지 않습니다. 몇 개 바뀌었는지는 프리셋 줄에 한 번 적습니다.

## 로고 묶음 (A2-E, 명세 5.6)

고객사가 플레이어 위에 띄우는 플레이어 로고(`logo.*`)를 데모에서 시험합니다. 광고 소재 안의 광고주 로고가 아닙니다. 올리기가 아직 없어서 이미지는 미리보기 전용 입력 `preview.logo`로 넣고, 나머지 값은 프리셋 값 위에 덮습니다. 저장된 프리셋은 바꾸지 않습니다.

### 구조 (컨트롤 묶음 다음, `fieldset.sa-optgrp` "로고")

1. **로고 이미지** `select.sa-input`(Field): 없음(기본) · 샘플 SVG (가로형) · 샘플 PNG (투명, 정사각형) · 주소 직접 넣기. 도움말 "미리보기 전용이라 저장하지 않아요. 로고 올리기(준비 중)는 PNG, JPEG, WebP만 받아요."
   - 샘플 둘은 데모 페이지와 같은 폴더의 `sample-logo.svg`, `sample-logo.png`입니다. 경로는 샘플 자막처럼 페이지 주소에서 계산합니다.
   - 선택지를 Segmented가 아니라 select로 둔 이유: 네 개이고 이름이 길어 360px 열에서 한 줄에 들어가지 않습니다.
2. **로고 이미지 주소** Field: "주소 직접 넣기"일 때만 보입니다(`hidden`, 선택 바로 아래). 자리표시 `/media/logo.png`, 도움말 "/로 시작하는 경로나 http(s):// 주소예요." 주소 규칙과 오류 문구는 썸네일 VTT 주소와 같습니다.
3. "없음"일 때만 이유 `p.sa-off-reason`(아래 "막기").
4. `div.sa-optgrp-body`: 이미지 다음의 모든 칸. 막을 때 이 상자에 `sa-off-body`를 붙입니다.
   - **위치** CornerPicker(legend "위치", 기본 오른쪽 위). 묶음 이름이 "로고"라서 "로고 위치"를 줄였습니다.
   - `div.sa-unit-grid` 안에 단위 붙은 숫자 칸 셋(Field의 단위 칸 규칙): **폭** 24–240px(기본 80, 도움말 "24–240 정수예요. 높이는 그림 비율을 따라요."), **불투명도** 10–100%(기본 80, "10–100 정수예요."), **여백** 0–48px(기본 12, "0–48 정수예요. 모서리에서 떨어진 거리예요."). 360px 열에서는 두 칸씩 줄바꿈합니다.
   - **링크 주소** `input[type=url]`, 자리표시 `https://example.com`, 도움말 "누르면 새 탭에서 열려요. 비우면 누를 수 없는 그림이에요."
   - **대체 텍스트** `maxlength=80`, 도움말 "링크가 있으면 꼭 넣어요. 링크 이름으로 읽히고 뒤에 ‘(새 탭에서 열림)’이 붙어요." 링크 칸이 비어 있지 않으면 `aria-required="true"`입니다. 필수 표시를 따로 그리지 않고 도움말로 알립니다.
   - SwitchList 두 줄: **광고 중 숨기기**(기본 켬, "광고가 시작되면 숨고 본편으로 돌아오면 다시 보여요."), **컨트롤과 함께 숨기기**(기본 끔, "컨트롤 막대가 숨을 때 로고도 함께 숨어요.").

### 주소 직접 넣기를 둔 이유

- 올리기(A2-3)가 생기기 전에 운영자가 자기 로고로 크기·위치·대비를 미리 볼 방법이 이것뿐입니다. 샘플 두 개로는 비율과 색이 다른 실제 로고를 시험할 수 없습니다.
- `preview.logo`가 이미 URL 하나를 받으므로 새 입력 규칙이 필요 없습니다(썸네일 주소와 같은 규칙).
- 칸은 고를 때만 보여서 기본 화면을 늘리지 않습니다.

### 막기 (컨트롤 묶음과 같은 규칙)

- 이미지 "없음": 이미지 select는 그대로 쓰고, 나머지는 `disabled`(CornerPicker는 `fieldset disabled`, 스위치 행은 `is-locked`)로 막습니다. 이유 "<b>로고 이미지를 고르면 나머지 칸을 쓸 수 있어요.</b> 지금은 플레이어에 로고가 없어요." 막힌 칸마다 `aria-describedby`로 이유를 잇습니다. 값은 지우지 않습니다.
- 기본 video 프리셋: 이미지 select까지 묶음 전체를 막습니다. 이유 "<b>기본 video 프리셋에서는 로고를 쓸 수 없어요.</b> Video.js 프리셋을 고르면 쓸 수 있어요." 값은 그대로 두고, Video.js 프리셋으로 돌아오면 다시 보입니다. 렌더 `logo`는 늘 `null`입니다(결정 27).
- 두 이유가 함께 맞으면 기본 video 이유 하나만 보입니다.

### 오류와 알림

- 이미지 주소 형식: "/로 시작하는 경로나 http(s):// 주소로 입력해 주세요. 상대 경로는 받지 않아요."(`is-error`)
- 이미지를 불러오지 못함(샘플 파일이 없을 때 포함): "이미지를 불러오지 못해 플레이어에 로고를 숨겼어요. 주소와 파일을 확인해 주세요."(`is-warn`, 이미지 칸 도움말 자리). 플레이어는 깨진 그림 대신 로고 자리를 숨기므로(명세 5.4) 데모가 이유를 글로 알려야 합니다. 데모가 같은 주소를 `Image`로 미리 불러 보고 판단하는 것을 제안합니다.
- 링크 주소 형식: "http:// 또는 https://로 시작하는 주소로 입력해 주세요."(스키마 `logo.href`는 절대 URL만 받습니다. `/` 경로도 막습니다.)
- 링크가 있는데 대체 텍스트가 비었음: "링크가 있으면 대체 텍스트를 입력해 주세요."(스키마 422와 같은 문장). 이때 플레이어는 링크 없이 그림만 보입니다(제안). 이름 없는 링크를 만들지 않기 위해서입니다.
- 대체 텍스트 80자 넘음: `maxlength`로 막아 오류가 나지 않습니다.
- 숫자 범위 밖: Field 단위 칸 문구("240px보다 커요. 24–240 사이의 정수로 입력해 주세요." 꼴).
- 틀린 값은 그 칸만 오류로 보이고, 플레이어와 주소 쿼리는 마지막으로 맞았던 값(없으면 프리셋 값)을 씁니다.

### 프리셋 값과 주소

- 위치·폭·불투명도·여백·링크·대체 텍스트·두 스위치는 프리셋 값입니다. 프리셋과 다르면 "프리셋과 다른 값 N개"에 세고 "프리셋 값으로 되돌리기"로 돌아갑니다.
- 이미지 선택과 주소는 미리보기 입력이라 세지 않고 되돌리기로 지우지 않습니다(썸네일 주소, 미디어 형식과 같음).
- 값은 주소 쿼리에 남습니다. 키 이름은 구현이 정하되 지금 데모 키 모양(camelCase)을 따릅니다. 제안: `logo`(`sample-svg`·`sample-png`·주소), `logoPosition`, `logoWidth`, `logoOpacity`, `logoMargin`, `logoHref`, `logoAlt`, `logoHideDuringAds`, `logoHideWithControls`.

### 무대에서 볼 점 (구현·QA 확인용)

- 샘플 두 개는 어두운 장면, 밝은 장면, 중간 밝기, `sample-poster.svg` 위에서 모두 보이게 만들었습니다(`design/assets/sample-logo/README.md`). 데모 무대는 포스터가 어두워서 처음 화면에서 잘 보입니다.
- 무대 바깥(`panel-2` 바탕)으로 로고가 넘치면 안 됩니다. 폭 240·여백 48을 390 폭 보기에서 확인합니다.
- 아래쪽 모서리: 컨트롤이 보이면 컨트롤 막대 위로 올라가고, 숨으면 여백만 남깁니다(제안). 컨트롤 막대 아이콘과 겹치지 않는지 봅니다.
- 왼쪽 위: 제목 보이기가 켜져 있으면 제목이 로고 오른쪽으로 비켜 앉는지 봅니다(제안).
- 광고 중 숨기기: 장면 바로가기 "미드롤 앞"으로 광고를 띄워 숨는지, 본편으로 돌아오면 보이는지 봅니다.
- 컨트롤과 함께 숨기기: 마우스를 치우고 컨트롤이 숨을 때까지 기다립니다. 움직임 줄이기 설정이면 바로 바뀌어야 합니다.
- 링크가 있을 때: Tab 순서가 컨트롤보다 앞이고, 어두운 장면 위에서 초점선이 보이며, 이름이 "데모 스토어 (새 탭에서 열림)"처럼 읽히는지 봅니다. 링크가 없으면 로고를 눌러도 재생·멈춤이 그대로 일어나야 합니다.
- 샘플 SVG는 가로로 길어서 기본 폭 80에서는 작은 글줄("SAMPLE LOGO")이 읽히지 않습니다. 의도한 것이며 폭 시험용입니다. 160 이상에서 읽힙니다.

## 설치 코드

- 카드 제목 "설치 코드". 아래 한 줄로 이 코드가 왜 이렇게 생겼는지 적습니다.
  - 사이트 적용 프리셋: "지금 설정 그대로예요. 사이트 적용 프리셋이라 data-preset을 넣지 않았고, 프리셋과 같은 값은 쓰지 않았어요."
  - 다른 프리셋: "지금 설정 그대로예요. 사이트 적용 프리셋이 아니라서 data-preset을 넣었고, 프리셋과 같은 값은 쓰지 않았어요."
- 로고 이미지가 "없음"이 아니면 설명 줄 아래에 `p.sa-small#cd-logo` 한 줄을 더합니다. "로고는 설치 코드에 넣지 않았어요. 로고는 프리셋 값이고 이미지 올리기는 준비 중이라, 지금은 데모에서만 보여요." "없음"이면 `hidden`입니다. 로고를 쓰지 않는 사람에게는 필요 없는 말이라 늘 두지 않습니다.
- CodeBlock 둘을 세로로 둡니다. "HTML · 자리 요소와 로더"(복사 "HTML 코드 복사"), "JS API"(복사 "JS API 코드 복사"). 탭으로 바꾸지 않습니다. 둘 다 보여야 비교하기 쉽고 탭 부품이 따로 필요 없습니다.
- 코드가 바뀌면 CodeBlock 규칙대로 복사 결과 문구를 지웁니다.

## 광고 진행 기록

- 카드 제목 "광고 진행 기록" + 오른쪽 "기록 지우기"(작은 버튼). 아래 Note "최근 20개만 이 화면에 보여요. 통계에는 남기지 않아요."
- 목록은 ActivityLog를 `div.sa-logbox[role=region][aria-labelledby][tabindex=0]` 안에 둡니다. 새 기록이 위에 쌓이고, 20개를 넘으면 오래된 것부터 지웁니다.
- 한 줄: `time`(시:분:초) + "<위치> <순번>/<개수> · <일>". 위치는 프리롤·미드롤·포스트롤, 일은 시작·끝남·건너뜀·클릭·오류·중단입니다.
- 빈 상태: `sa-empty` "아직 광고 진행이 없어요" + "재생하면 여기에 쌓여요."
- 알림 영역이 아닙니다(PlayerStage의 최근 광고 진행 한 줄과 같은 이유).
