# A2 플레이어 화면 디자인 인계

광고 전용 스킨(`solad-video-skin`)과 광고 패키지(`packages/extensions/ads`)에 새로 들어가는 화면 요소의 값이다. 이 요소들은 관리자 부품이 아니라 플레이어 스킨이라서 `design/`에 두지 않는다. 관리자에서는 `design/components/PlayerMock`으로 그림만 그린다.

- 근거 캔버스: "A2 플레이어 설정 디자인" https://claude.ai/artifact/MnQQakBwfjF4SHASB1EChB (비공개)
  - I: 플레이어 화면
  - H: 테마 미리보기
  - C: 로고
  - D: 컨트롤
  - G: 광고 화면
  - K: 도움말 모션
- 근거 명세: `.agents/plans/ads-player-customization-spec.md` 5절 표, 6.1·6.3절, 결정 24–29
- 값의 출처 표시:
  - **명세**: 명세 필드 표에 있는 값이다.
  - **캔버스**: 캔버스 그림의 값이다.
  - **제안**: 아직 정하지 않은 값이다.
- 색: 플레이어는 관리자 토큰(`tokens.css`)을 불러오지 않는다.
  - 색 이름은 기본 스킨 변수와 명세 필드로 적는다.
  - 캔버스 그림의 hex 값은 그림용이다. 스킨에 같은 역할의 변수가 있으면 그 변수를 쓴다.
- 폭 기준:
  - 640: 640×360 플레이어.
  - 360: 360×203 플레이어.
  - 스킨의 실제 분기점은 기본 스킨의 컨테이너 쿼리를 따른다. 여기서는 그 두 폭에서 보일 모습만 정한다.

## 1. ±초 버튼

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 요소 | `<media-seek-button seconds="-N">`, `<media-seek-button seconds="N">` 한 쌍 | 명세 6.1 |
| 값 | `controls.seekButtons`: `null`(숨김, 기본)·5·10·15·30 | 명세 |
| 자리 | 컨트롤 막대 첫 줄, 재생 버튼 바로 뒤. 순서는 뒤로 → 앞으로, 그 뒤가 음량 | 캔버스 I, D |
| 크기 | 다른 컨트롤 버튼과 같은 칸. 캔버스 기준 640은 36×32, 360은 28×26. 아이콘은 640에서 20px, 360에서 16px | 캔버스 I(`pm-btn`) |
| 간격 | 버튼 사이 2px. 기본 스킨 버튼 간격을 따른다 | 캔버스 I |
| 모양 | 둥근 화살표 아이콘(뒤로는 반시계, 앞으로는 시계 방향)과 아이콘 안 초 숫자. 숫자는 장식이다 | 캔버스 I |
| 360 | 숫자를 빼고 아이콘만 둔다. 버튼은 남긴다 | 캔버스 I |
| 상태 | 기본, hover, `:focus-visible`, 누름은 기본 스킨 버튼과 같다. 영상 처음·끝에서도 막지 않는다(기본 스킨 동작) | 캔버스 I |
| 함께 바뀌는 것 | 켜면 화면 왼쪽·오른쪽 두 번 탭 탐색 폭도 같은 초로 맞춘다 | **제안**(명세 6.1-6) |
| 접근성 | 이름은 "10초 뒤로", "10초 앞으로"처럼 초를 넣는다. 아이콘 안 숫자는 `aria-hidden`이다. 단축키는 바꾸지 않는다 | 캔버스 I |

## 2. 로고 자리

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 위치 | `logo.position`: `top-left`·`top-right`(기본)·`bottom-left`·`bottom-right` | 명세 |
| 여백 | `logo.margin` 0–48px, 기본 12. 플레이어 가장자리에서 로고 가장자리까지 | 명세 |
| 폭 | `logo.width` 24–240px, 기본 80. 높이는 이미지 비율을 따른다 | 명세 |
| 불투명도 | `logo.opacity` 10–100%, 기본 80 | 명세 |
| 쌓임 | 영상 위, 컨트롤·광고 화면 아래 | 캔버스 I |
| 아래쪽 모서리 | 컨트롤이 보이면 컨트롤 막대 위로 올라간다. 캔버스 기준 바닥에서 640은 64px, 360은 50px 위다. 실제 값은 "컨트롤 막대 높이 + 여백"이다. 컨트롤이 숨으면 여백만 남기고 모서리로 내려온다 | 캔버스 I, H. 올라가는 동작은 **제안** |
| 왼쪽 위 | 제목이 있으면 제목이 로고 오른쪽으로 비켜 앉는다 | **제안**(캔버스 I) |
| 360 | 값은 같다. 폭이 플레이어의 1/3보다 크면 줄일지는 정하지 않았다 | 열린 질문 |
| 광고 중 | `logo.hideDuringAds` 기본 true. 광고가 시작되면 숨기고 본편으로 돌아오면 보인다 | 명세, 캔버스 I·K |
| 컨트롤과 함께 숨기기 | `logo.hideWithControls` 기본 false. 켜면 컨트롤이 숨을 때 함께 숨긴다. 컨트롤 숨김 상태를 읽는 방법은 구현 때 확인한다(Q6) | 명세 결정 28 |
| 움직임 | 나타나고 사라질 때는 기본 스킨 컨트롤의 숨김 전환과 같은 시간과 가속을 쓴다. 움직임 줄이기 설정이면 바로 바꾼다 | **제안** |
| 링크 | `logo.href`가 있으면 `<a target="_blank" rel="noopener noreferrer">`로 감싼다. 이름은 `logo.alt`이고 "(새 탭에서 열림)"을 덧붙인다. 초점선은 기본 스킨 초점선을 쓴다 | 명세, 캔버스 I |
| 링크 없음 | 장식 그림이다. `alt=""` | 캔버스 I |
| 초점 순서 | 링크 로고는 Tab 순서에서 컨트롤보다 앞이다 | **제안**(캔버스 I) |
| 기본 video | `playerType: native`이면 로고를 그리지 않는다. 값은 저장할 때 `null`이 된다 | 결정 27 |

## 3. 광고 진행 막대

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 켜기 | `ads.progress.bar` 기본 false | 명세 |
| 요소 | 광고 오버레이 안의 새 요소, `part="progress"`, `aria-hidden="true"` | 명세 6.3 |
| 자리 | 광고 화면 맨 아래. 왼쪽 0, 오른쪽 0, 바닥 0, 플레이어 전체 폭 | 캔버스 I |

| 바탕 | 흰색 20% 투명(캔버스 `#ffffff33`) | 캔버스 I |

| 모서리 | 없음(직각) | 캔버스 I |

| 360 | 높이와 색은 640과 같다 | 캔버스 I |

## 4. 시간 문구와 화면 읽기용 글자

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 켜기 | `ads.progress.timer` 기본 true. 문구는 `labels.timer`(기본 `{elapsed} / {duration}`, 늘 한국어 문구 묶음) | 명세, 결정 29 |
| 자리 | 광고 조작 줄 왼쪽, 음량 버튼 뒤. 기존 `part="timer"` | 명세, 캔버스 I |
| 글자 | 숫자 12.5px, 굵기 500, 자릿수 고정(tabular-nums). 360에서도 12px보다 작게 줄이지 않는다 | 캔버스 I(`pm-ad-ctl`) |
| 끔 | 화면에서만 숨긴다. 요소를 지우지 않고 시각적으로만 숨긴다(1px 상자와 `clip-path: inset(50%)`, 절대 위치). 광고 조작 줄 안에 그대로 두어 읽는 순서가 바뀌지 않게 한다 | 결정 24, 캔버스 I |
| 알림 | 켜든 끄든 `aria-live`를 붙이지 않는다. 초마다 바뀌는 글자를 알리면 소리가 끊이지 않는다. 사용자가 그 자리로 갔을 때만 읽힌다 | 캔버스 I |
| 진행 막대와 관계 | 막대가 켜져 있어도 시간 정보는 이 글자가 전한다. 막대는 `aria-hidden`이다 | 명세 6.3 |

## 6. 폭별 규칙 요약

| 폭 | 본편 | 광고 중 |
| --- | --- | --- |
| 640 | 컨트롤 한 줄: 재생, ±초(숫자 있음), 음량, 시간과 시간 막대, 자막, 설정, PiP, 전체화면. 로고 높이 기준 아래 모서리는 바닥에서 64px | 배지 왼쪽 위, 조작 줄 아래, 진행 막대 바닥 3px |
| 360 | 시간 막대가 위 줄로 올라가고, 버튼 줄은 재생, ±초(아이콘만), 음량, 빈 칸, 자막, 설정, PiP, 전체화면. PiP는 기본 스킨 동작 그대로 둔다(결정 25). 아래 모서리 로고는 바닥에서 50px | 640과 같고 크기만 줄어든다(5절) |

- 캐스트와 AirPlay 버튼은 두 폭 모두 없다(명세 6.1).
- 끈 컨트롤은 그 자리를 비우지 않고 빠진다. 설정 메뉴 항목이 모두 꺼지면 설정 버튼을 숨긴다(명세 6.1-6).

## 7. 관리자 쪽 부록 (design/에 없는 두 부품)

아래 두 부품은 `integrations/ads-manager/ui`에만 있고 `design/components`에 폴더가 없다. 그래서 이번에 design/로 옮기지 않았다. A2 화면 작업(ads-admin-ui)에서 반영할 규칙만 적는다.

### 저장 막대 (`aa-savebar`, `ui/src/app/app.css`)

- 사이트 적용 프리셋을 고칠 때 문구는 "사이트 적용 프리셋이에요. 저장하면 사이트의 플레이어가 바뀌어요."다. 근거는 캔버스 B 1280·390이다.
- 390에서는 문구를 짧게 두고, 저장 버튼이 한 줄을 다 쓴다. 막대는 화면 양옆 끝까지 닿는다. 근거는 캔버스 B 390이다.
- 오류가 있으면 "고칠 칸 N개" 문구를 SectionNav 오류 수와 맞춘다.
- 저장 중 상태는 지금처럼 StatusMessage로 알린다.

### ThemePreview (`ui/src/player/theme-preview.tsx`, 실제 iframe 미리보기)

- 위에 Segmented "본편 · 광고 중" 장면 고르기를 둔다. 장면은 저장 값이 아니다. 근거는 캔버스 H다.
- 컨트롤 켜기·끄기, ±초, 로고(위치·여백·폭·불투명도·광고 중 숨김), 광고 진행 표시 3개를 반영한다.
- 광고 장면은 0:07에 멈춘 그림이다. 실제 광고처럼 시간이 흐르지 않는다. 근거는 캔버스 H다.
- 768과 390에서는 접힌 채 시작한다. 390에서 열면 칸 폭 358px에 맞춘다. 근거는 캔버스 B 768·390이다.
- 보여 줄 수 없을 때는 기존 오류 문구를 그대로 쓴다.
