# 데모·설명서·도움말과 플레이어 미리보기 문구표 (A2-D)

2026-10-21 ads-admin-designer. 계약은 `ads-demo-preview-spec.md`, 화면은 `design/components/`의 DocShell, PhaseTag, OptionTable, PlayerStage, DemoBench, PlayTest, PlayerPreview입니다. 이 표의 문구를 그대로 쓰고, 바꿀 때는 이 표를 먼저 고칩니다.

- 도움말·설명서 **본문의 사실 내용**은 ads-implementer가 코드에서 씁니다. 이 표는 절 제목, 앵커, 화면 문구만 정합니다.
- `<…>`는 바뀌는 값입니다. `N`은 숫자입니다.

## 1. 어조와 용어

### 어조

- **관리자 화면:** 해요체입니다(`design/README.md` 문구 규칙).
- **공개 페이지(데모·설명서·도움말·재생 테스트):** 해요체입니다.
  - 읽는 사람은 이 매니저를 쓰는 사이트의 운영자와 개발자입니다. 관리자 화면을 쓰는 사람과 같습니다.
  - 옵션 표의 설명은 관리자 `playerOptions`와 같은 데이터(해요체)에서 옵니다(명세 4절). 표 위 문장만 합니다체로 쓰면 한 화면 안에서 어조가 섞입니다.
  - 관리자 도움말(`terms.ts`)과 같은 문장을 옮겨 쓸 수 있습니다.
  - 명세의 "샘플 미디어가 없습니다"는 이 규칙에 따라 "샘플 미디어가 없어요"로 씁니다.
- 제목, 라벨, 표 머리, 버튼은 어조 없이 명사나 동사구로 씁니다("설치 코드 두 줄", "프리셋 값으로 되돌리기").
- 글자 값과 코드 이름은 `code`로 쓰고 옮기지 않습니다(`data-preset`, `true`).

### 용어

`ui/src/help/terms.ts`를 따릅니다. 화면에 자주 나오는 말은 다음과 같습니다.

| 쓰는 말 | 쓰지 않는 말 |
| --- | --- |
| 사이트 적용 프리셋 | 기본 프리셋, 대표 프리셋 |
| 로더 | 로더 스크립트, 설치 스크립트 |
| 자리 요소 | 플레이스홀더, 컨테이너 div |
| 플레이어 화면 언어 | UI 언어, 로캘 |
| 광고 화면 | 광고 오버레이 |
| 프리롤·미드롤·포스트롤 | pre/mid/post |
| 게시본 | 게시 버전(목록 밖) |
| 기본 video | 네이티브 플레이어 |

### 새 용어 정의(관리자 도움말 `terms.ts`에 더할 문장)

| 용어 | 정의 한 줄 |
| --- | --- |
| 데모 | 프리셋을 고르고 설정을 바꿔 보며 플레이어를 확인하고, 그 상태의 설치 코드를 복사하는 공개 페이지예요. 저장하지 않고 통계에 남기지 않아요. |
| 설명서 | 플레이어를 사이트에 설치하고 프리셋과 지면 편성을 운영하는 순서를 적은 공개 페이지예요. |
| 도움말 | 설치 코드, 자리 요소 속성, JS API, 프리셋 설정 옵션을 모은 공개 참조 페이지예요. 관리자 화면의 옵션 설명 링크가 이 페이지로 와요. |
| 재생 테스트 페이지 | 게시한 편성을 실제 서비스와 같은 수집 경로로 재생하는 페이지예요. 재생 결과가 통계에 쌓여요. |

- 관리자 용어 "게시본 재생 테스트"는 재생 테스트 페이지를 여는 일입니다. 두 항목을 `related`로 잇습니다.
- 관리자 도움말 화면에서 "게시 전 미리보기"(`preview`)의 문장 "프리셋을 쓰지 않아요"는 A2-D부터 틀립니다. 이제 고른 프리셋을 적용합니다. 그 항목과 `player-preset` 상세의 같은 문장을 고쳐야 합니다(ads-admin-ui).

| 스위치 설명 | 광고가 시작되면 숨고 본편으로 돌아오면 다시 보여요. |
| 스위치 | 컨트롤과 함께 숨기기 |
| 스위치 설명 | 컨트롤 막대가 숨을 때 로고도 함께 숨어요. |
| 막힘 이유: 이미지 "없음" | **로고 이미지를 고르면 나머지 칸을 쓸 수 있어요.** 지금은 플레이어에 로고가 없어요. |
| 막힘 이유: 기본 video 프리셋 | **기본 video 프리셋에서는 로고를 쓸 수 없어요.** Video.js 프리셋을 고르면 쓸 수 있어요. |

### 오류와 알림

| 자리 | 문구 |
| --- | --- |
| 이미지 주소 형식(`is-error`) | /로 시작하는 경로나 http(s):// 주소로 입력해 주세요. 상대 경로는 받지 않아요. (썸네일 주소와 같음) |
| 이미지를 불러오지 못함(`is-warn`) | 이미지를 불러오지 못해 플레이어에 로고를 숨겼어요. 주소와 파일을 확인해 주세요. |
| 링크 주소 형식 | http:// 또는 https://로 시작하는 주소로 입력해 주세요. |
| 링크가 있는데 대체 텍스트 없음 | 링크가 있으면 대체 텍스트를 입력해 주세요. (스키마 `logo.alt` 422와 같음) |
| 숫자 범위 밖(예: 폭) | 240px보다 커요. 24–240 사이의 정수로 입력해 주세요. (Field 단위 칸 규칙) |

### 플레이어 로고 링크 이름 꼬리 (명세 5.4, 바꾸지 않음)

링크 이름은 대체 텍스트 뒤에 플레이어 화면 언어의 꼬리를 붙입니다.

| 언어 | 꼬리 |
| --- | --- |
| ko | (새 탭에서 열림) |
| en | (opens in a new tab) |
| ja | （新しいタブで開きます） |
| zh-CN | （在新标签页中打开） |

- 띄어쓰기: ko·en은 대체 텍스트와 꼬리 사이에 공백 하나를 둡니다. ja·zh-CN은 전각 괄호라 공백 없이 붙입니다(제안, 구현이 정함).

### 옵션 표 설명: 새 창 → 새 탭 (A2-E-FIX-PLAYER, 2026-10-22)

로고 링크와 안내 글자는 새 탭에서 열리므로 "새 창" 대신 "새 탭"으로 맞춥니다(`options.js`, 꼬리 "(새 탭에서 열림)"과 데모 링크 칸 도움말에 맞춤).

| 행 | 이전 | 지금 |
| --- | --- | --- |
| `logo.href` 설명 | 로고 링크예요. 새 창으로 열려요. | 로고 링크예요. 새 탭에서 열려요. |
| `ads.labels.newWindow` 설명(기본값 "새 탭에서 열림") | 새 창 안내 글자예요. 기본 video 플레이어에는 지금도 적용돼요. | 새 탭 안내 글자예요. 기본 video 플레이어에는 지금도 적용돼요. |

- 경로 이름 `ads.labels.newWindow`는 데이터 계약이라 그대로 둡니다.
