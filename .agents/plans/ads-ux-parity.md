## 이번 구현 계약

1. 광고 소재는 전체 프레임에 `object-fit: contain`으로 유지하고 조작부는 scrim 위에 겹친다. 좁은 플레이어에서도 주요 조작부가 겹치거나 프레임 밖으로 나가지 않는다.
2. 현재 Video.js 스킨의 폰트·색·포커스·크기·모서리 토큰을 활용하고 플러그인 전용 CSS 변수/스타일 훅으로 고객별 조정이 가능해야 한다. Shadow DOM의 광고 미디어 분리 경계는 유지한다.
3. 아이콘형 재생/일시정지·음소거·전체화면과 명확한 광고 순서·시간·스킵·광고주 CTA를 제공한다. 시간은 실제 미디어 시간/길이로 표시하며 미확정 길이를 0초로 오인시키지 않는다.
4. 한국어/영어 문구와 v10의 문구 재정의 의도를 지원한다. 문구 변경이 광고 편성 재요청·광고 재시작을 일으키면 안 된다.
5. 로딩, 일시정지, 재생 권한 차단 메시지는 현재 상태와 일치해야 한다. 연속 광고 전환 시 숨겨진 CTA/스킵에 포커스를 남기지 않고 광고 종료 후 원래 본편 조작으로 복귀한다.
6. 컨테이너 전체화면 진입/종료와 스코프 내 키보드 조작을 제공하되 광고 seek는 허용하지 않는다. 미지원 환경에서는 미지원 동작을 노출하지 않는다. 기존 종료/취소/포커스/관측·통계 계약을 보존한다.
7. 사용자용 예제 페이지는 현재 플레이어와 광고 상태를 읽기 쉽게 보여주고 media/engine/video/content 쿼리를 보존한다. 관리자 미리보기는 광고 상태/오류/완료를 표시하고 `preview: true`를 유지한다.

스킵 시간은 현재 C0의 정수 1초 이상 또는 `null` 계약을 유지한다. 초기 QA 요청에 포함한 `0`은 오케스트레이터의 잘못된 테스트 입력이었다. 원래 요청 JSON을 입력 검증 실패 사례로 보존하며, 정상 UI 검증은 별도 `ux-review-valid-20261018` 편성에서 1초를 사용한다. 원래 0초 사례가 통과한 것으로 기록하지 않는다.

라벨 API는 DOM controller의 `ui: { locale?, labels? }` 및 `updateUI(ui)`, HTML의 상속 `lang`과 기존 문구 속성으로 정한다. 광고 논리 세션·편성 소비와 독립적으로 갱신한다.
