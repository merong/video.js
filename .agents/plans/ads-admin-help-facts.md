### 2.1 광고 위치

**`ad-break` — 광고 구간** (`광고 구간 {n}개`, `구간 삭제`)
- 뜻: 본편의 한 시점(시작 전·재생 중 특정 초·종료 후)에 끼어드는 광고 묶음이다. 한 구간 안에 광고 항목이 1~20개 순서대로 들어가고 차례로 재생된다. 업계의 ad pod와 같은 개념이다.
- 수치: 편성당 구간 최대 100개, 구간당 광고 1~20개, 빈 구간은 저장 불가. 프리롤·포스트롤은 각 1개, 미드롤은 같은 초에 1개.
- 근거: `UI/api/model.ts:74-75,133,158`, `BreakEditor.tsx:47-50,63,178`, `S/Schedules.php:26,49,60-66`, `X/core/playback.ts:192,207,216,229`.
- 상태: 지금 동작.
- 모션: 본편 타임라인 막대 위 0초·10초·끝 지점에 구간 블록이 끼어들고 블록 안에 광고 카드가 2~3장 쌓인다.
- HelpLink: `BreakEditor.tsx` 카드 제목 `광고 구간 {n}개`.

**`pre-roll` — 프리롤** (`프리롤 · 시작 전`)
- 뜻: 본편이 처음 재생되기 직전에 나오는 구간이다. 사용자가 재생을 누른 뒤 시작하며 자동 재생하지 않는다.
- 근거: `BreakEditor.tsx:18,67`, `X/dom/controller.ts:87-89,182-183`, `X/core/scheduler.ts:102-110`.
- 상태: 지금 동작.
- 모션: 재생 버튼을 누르면 본편 대신 광고 블록이 먼저 채워지고 끝나면 본편이 0초부터 시작한다.
- HelpLink: `BreakEditor.tsx` 구간 추가 버튼 그룹 `광고 구간 추가`, 구간 카드 제목 `프리롤 · 시작 전`.

**`mid-roll` — 미드롤** (`미드롤 · 재생 중`, 필드 `본편 재생 위치 (초)`)
- 뜻: 본편 재생 시각(본편 currentTime, 초)이 지정한 위치를 지나면 나오는 구간이다. 자연 재생으로 여러 미드롤을 지나면 시간 순서대로 모두 나온다. 앞으로 건너뛰기(seek)로 여러 미드롤을 지나면 가장 이른 하나만 나오고, 뒤로 감으면 대기 중인 구간이 지워진다. 한 번 시작한 구간은 다시 나오지 않는다.
- 수치: 0보다 큰 초(소수 허용, UI `min 0.01`, `step any`). 새 미드롤 기본값 10초. 서버 상한 31,536,000초. 본편 길이 이상이면 플레이어가 **편성 전체(프리·포스트 포함)**를 끄고 `invalid_duration`을 보고한다. 서버는 본편 길이를 검사하지 않는다.
- 근거: `BreakEditor.tsx:19,54,163-170`, `UI/api/model.ts:146`, `S/Schedules.php:50-56`, `X/core/scheduler.ts:114-131,142-144`, `X/core/playback.ts:291`, `X/dom/controller.ts:294-315`.
- 상태: 지금 동작.
- 모션: 재생 헤드가 10초 표시를 지나는 순간 본편이 멈추고 광고 블록이 재생된 뒤 10초 지점에서 본편이 이어진다.
- HelpLink: `BreakEditor.tsx` 필드 `본편 재생 위치 (초)`.

**`post-roll` — 포스트롤** (`포스트롤 · 종료 후`)
- 뜻: 본편이 끝난(`ended`) 뒤 나오는 구간이다. 끝까지 seek하면 남은 미드롤은 지워지고 포스트롤만 나온다. 포스트롤 뒤 본편은 다시 재생되지 않는다.
- 근거: `BreakEditor.tsx:20,73`, `X/core/scheduler.ts:95-99`, `X/dom/controller.ts:240,662`, `C1:60`.
- 상태: 지금 동작.
- 모션: 재생 헤드가 끝에 닿으면 광고 블록이 이어지고 끝나면 화면이 종료 상태로 멈춘다.
- HelpLink: 구간 카드 제목 `포스트롤 · 종료 후`.

**`ad-item` — 광고 항목과 순서** (`{n}. {소재 이름}`, `위로`/`아래로`/`광고 제거`)
