# A2-E 플랫 프리셋, 무대 테두리, 목록 미리보기, ±초·자막 켜기, 로고 미리 준비

- 작성: 2026-10-21, 오케스트레이터. 사용자 요청 네 가지를 한 단위로 묶는다. 이 문서와 `ads-player-schema-v2.md`가 다르면 이 문서를 따른다. 바꿀 때는 오케스트레이터에게 먼저 알린다.
- 사용자 요청(원문 요지)
  1. 프리셋에 flat이 없다. 플레이어 표시 영역 레이어의 테두리를 없애야 프리셋이 적용된 것을 정확히 확인할 수 있다. flat 프리셋을 더하고 테두리를 조정한다.
  2. 관리자 프리셋 목록에 미리보기를 더하고, 누르면 모달 레이어로 플레이어를 보인다.
  3. 플레이어 예제 설정에 이전·이후 아이콘 표시 여부를 더한다. 자막을 켜고 끌 수 있게 한다. 자막을 켰는데 영상에 자막이 없으면 "자막 없음"을 보이고 사용자의 자막 켜기·끄기 아이콘을 비활성으로 둔다.

## 1. 플랫 프리셋과 테두리 (요청 1)

### 1.1 무대 레이어

- 지금 `.sa-stage-view`(데모 무대, 관리자 미리보기 무대)가 플레이어 위에 모서리 12px(`--radius-card`), 안쪽 1px 선, 모서리 잘라내기를 더한다. 그래서 프리셋의 모서리와 테두리가 무대 모양에 가려진다. 예를 들어 기본 스킨 모서리 28px, `rounded` 12px, 플랫 0px이 모두 같은 카드 모양으로 보인다.
- **결정:** 무대 레이어는 플레이어 위에 모서리·선·잘라내기를 더하지 않는다. 플레이어가 고객 페이지에서와 같은 모양으로 보여야 한다. 배경은 남겨 플레이어 모서리가 드러나게 한다. 폭 보기 축소에 필요한 `overflow`는 남겨도 되지만 모서리를 자르지 않는다. 빈 상태(`is-empty`)의 모양은 디자인이 정한다.
- 데모(`demo.css`의 `.ex-player`), 미리보기 프레임(`preview.html`의 `.ex-frame`)도 모서리나 선을 더하지 않는지 함께 본다.

### 1.2 내장 프리셋 `flat`

- 내장은 4개이고 순서는 `default`, `flat`, `rounded`, `accent`다. 모두 `playerType: "videojs"`.

| id | 이름 | 값 |
| --- | --- | --- |
| `flat` | 플랫 | `theme.borderRadius: 0`, `theme.borderColor: "#00000000"` |

- 다른 내장의 값은 그대로다. `rounded`는 테두리 색을 비운 채(스킨 기본, 10% 검정) 둔다.

### 1.3 `theme.borderColor` 형식

- `theme.borderColor`만 `#rrggbb` 또는 `#rrggbbaa`(소문자 16진수)를 받는다. 다른 색 필드는 `#rrggbb` 그대로다. `ads-player-schema-v2.md` 5절의 "필요하면 이 필드만 `#rrggbbaa`로 넓힌다"를 이번에 적용한다.
- 대문자는 v1 규칙과 같이 다룬다(지금 색 필드가 대문자를 어떻게 다루는지 따른다).
- CSS는 그대로 `--media-border-color: <값>`이다.
- 편집기: "테두리 색" 아래 체크 "테두리 없음"을 둔다. 켜면 값은 `#00000000`이고 색 입력은 막힌다. 끄면 비운 값(스킨 기본)으로 돌아간다. 값의 투명도가 `00`이면 체크가 켜진 채 열린다. 글자 입력은 8자리를 받는다. 색 고르기 칸은 투명도를 다루지 못하므로 고르면 불투명 `#rrggbb`가 된다.
- 문구
  - 테두리 색 형식 오류: "#과 16진수 6자리로 입력해 주세요. 투명도를 넣으려면 8자리로 써요. 예: #cdf352, #00000026"
  - "테두리 없음" 도움말: "켜면 플레이어 둘레에 선을 그리지 않아요."
  - 옵션 설명(`theme.borderColor`·`--media-border-color`): "플레이어 둘레의 가는 선 색이에요. 8자리로 투명도를 줄 수 있고 #00000000이면 선이 없어요. 내장 프리셋 \"플랫\"은 선이 없어요."
  - 옵션 설명(`theme.borderRadius`·`--media-border-radius`): "플레이어 모서리 둥글기예요. 광고 화면 모서리도 따라가요. 내장 프리셋 \"플랫\"은 0px, \"둥근 테두리\"는 12px예요."
  - 내장 목록 문장: "내장 프리셋은 기본, 플랫, 둥근 테두리, 강조색 네 가지예요."

## 2. 프리셋 목록 미리보기 (요청 2)

- 목록(`#/players`)의 각 줄에 "미리보기" 버튼을 둔다. 이름은 "<이름> 미리보기"다. 자리는 디자인이 정한다(기본안: 작업 칸 맨 앞).
- 누르면 모달 대화상자(`dialog.sa-dialog`, `showModal()`)로 그 프리셋의 플레이어를 보인다.
  - 제목 "<이름> 미리보기"와 닫기 버튼. 본문은 편집기·내장 화면과 같은 플레이어 미리보기(무대, 폭 보기, 장면 바로가기, 최근 광고 진행, 데모에서 열기)다. 바닥줄에 "닫기".
  - 플레이어용 넓은 폭 변형이 필요하다(지금 `sa-dialog`는 480px). 폭·높이·좁은 화면 규칙은 디자인이 정한다.
  - 저장된 값으로 재생한다(`demo={{presetId, unsaved:false}}`와 같은 뜻). 그 프리셋에 저장하지 않은 입력이 있으면 저장된 값이라는 것을 알린다(문구는 디자인).
  - Esc와 닫기로 닫힌다. 닫으면 연 버튼으로 초점이 돌아간다. 닫으면 플레이어를 없애 소리가 남지 않는다. 통계는 보내지 않는다(미리보기 규칙 그대로).

## 3. ±초 버튼과 자막 켜기·끄기 (요청 3, A2-2의 일부)

### 3.1 범위

- "이전·이후 아이콘"은 `controls.seekButtons`(±초 건너뛰기 버튼)로 본다.
- 이 두 항목은 `ads-player-customization-spec.md` A2-2(광고 전용 스킨 `solad-video-skin`, 6.1절)의 일부다. 기본 스킨에는 ±초 버튼이 없으므로 6.1절대로 기본 비디오 스킨을 복사한 광고 전용 스킨을 만든다.
- 이번에 적용하는 것: 스킨 복사(6.1절 1번 캐스트·AirPlay 제거 포함), `controls.seekButtons`, `controls.captions`, 자막 입력(3.3절). 다른 켜기·끄기(`quality`, `audioTrack`, `playbackRate`, `pip`, `fullscreen`, `thumbnails`), `input.*`, 로고는 이번 범위가 아니다. 지금처럼 A2-2·A2-3 표시를 유지한다.

### 3.2 동작

- `controls.seekButtons`: `null`이면 숨김. 5·10·15·30이면 컨트롤 막대에 뒤로·앞으로 버튼을 그 초로 보인다. 두 번 탭 탐색 폭도 같은 값으로 맞출 수 있으면 맞춘다(6.1절 6번 제안, 안 되면 보고).
- `controls.captions`
  - `false`: 자막 버튼, 설정 메뉴의 자막 항목, `c` 단축키를 모두 끈다. 키보드 탐색 순서에도 남지 않는다.
  - `true`이고 영상에 자막·캡션 트랙이 있으면: 지금 기본 스킨처럼 켜고 끈다.
  - `true`이고 자막·캡션 트랙이 없으면: 자막 버튼을 보이되 비활성(`aria-disabled`, 초점은 받음)으로 둔다. 이름과 툴팁은 "자막 없음"이다. 눌러도 아무 일이 없고 `c` 단축키도 아무 일이 없다.
  - "자막 없음" 문구는 플레이어 화면 언어를 따른다. ko "자막 없음", en "No captions", ja "字幕なし", zh-CN "无字幕".
- 좁은 폭에서 기본 스킨이 자막 버튼을 숨기는 규칙(`media-max-lg:hidden`)은 그대로 따른다. 바꿔야 하면 보고한다.
- `native` 플레이어에는 적용하지 않는다(스키마 규칙 그대로, 값이 있으면 422).

### 3.3 자막 입력

- 자막이 없으면 켜기·끄기를 확인할 수 없으므로 로더 입력을 하나 더한다.
  - 자리 요소 `data-captions`(WebVTT URL 하나). JS API 값 이름 `captions`. `data-thumbnails`와 같은 URL 규칙과 같은 출처 규칙을 쓴다.
  - 로더는 `<track kind="subtitles" srclang="<플레이어 화면 언어>" label="<언어 이름>">`으로 붙인다. 기본으로 켜지 않는다(`default` 없음).
- 데모 샘플용 자막 파일 `public/examples/sample-captions.vtt`(한국어 몇 줄)를 둔다.

### 3.4 데모와 편집기

- 데모 설정 옵션에 묶음 "컨트롤"을 더한다: "이전·이후 버튼" 켜기·끄기와 초 선택(5·10·15·30, 켤 때 기본 10), "자막" 켜기·끄기, "자막 VTT 주소"(비우면 자막 없음, "샘플 자막 쓰기" 같은 손쉬운 채우기는 디자인이 정한다).
- `native` 프리셋이면 이 묶음은 이유와 함께 막힌다(지금 데모의 Video.js 전용 항목 규칙을 따른다).
- 관리자 편집기에 "컨트롤" 절을 더하고 같은 두 항목만 둔다. 다른 컨트롤 항목은 이번 범위가 아니다.
- 설치 코드: `data-captions`는 설치 속성이다. `seekButtons`·`captions`는 프리셋 값이다(`display.poster`처럼 다룬다).
- 도움말(`options.js`, `help.html`)과 관리자 옵션표(`player-options.ts`)에서 두 항목의 단계 표시를 "적용"으로 바꾸고, `data-captions` 행을 더한다.
- 주의: `controls.captions`의 기본값은 `true`다. 자막이 없는 영상은 모두 비활성 자막 버튼이 보이게 된다. 사용자 요청 그대로이고 보고에 적는다.

## 5. 로고 미리 준비 (요청 4, A2-3의 앞부분)

- 사용자 요청(원문 요지): 업체 광고 로고 표시 기능도 예제에서 시험할 수 있게 미리 준비한다. 업체 로고는 SVG나 투명 PNG 등으로 준비한다.

### 5.1 범위

- "업체 로고"는 고객사가 자기 플레이어 위에 띄우는 플레이어 로고(`logo.*`, 명세 결정 19·28, 넘김 문서 2절)로 본다. 광고 소재 안의 광고주 로고가 아니다.
- 이번에 하는 것: 광고 전용 스킨의 로고 자리, 렌더의 `logo` 모양, 미리보기 전용 로고 이미지 입력(`preview.logo`), 샘플 로고 두 개, 데모 "로고" 묶음, 도움말 문장.
- 이번에 하지 않는 것: 로고 업로드(`logo.assetId`는 계속 `null`만 받는다), 관리자 편집기 로고 절(LogoUpload, A2-3), 공개 렌더의 로고 URL, 백엔드. 관리자 옵션표의 로고 행 단계 표시는 A2-3 그대로다.

### 5.2 렌더 `logo`

- `null` 또는 `{ src, position, margin, width, opacity, href, alt, hideDuringAds, hideWithControls }`. 비운 값은 기본값(`top-right`, 12, 80, 80, `null`, `null`, `true`, `false`)으로 채운다.
- 지금 `src`는 `preview.logo`에서만 온다. 그 밖의 값은 프리셋의 `logo.*`(JS `overrides.logo` 포함)에서 온다. A2-3에서는 업로드한 이미지의 공개 URL이 같은 `src` 자리에 들어간다.
- `native`는 늘 `null`이다(결정 27). 이미지가 없으면 `null`이다. 그래서 백엔드 공개 렌더와 그 시험 기대값은 바뀌지 않는다.

### 5.3 미리보기 입력 `preview.logo`

- 이미지 URL 문자열 하나. URL과 출처 규칙은 `thumbnails`와 같다. 틀리면 그 값만 버리고 기존 미리보기 입력 오류와 같은 방식으로 알린다.
- `preview` 경로(데모, 미리보기 프레임)에서만 읽는다. `data-*` 속성과 일반 JS API에는 열지 않는다. 로고처럼 보이는 모습은 운영자 몫이라는 명세 4절 규칙 그대로다. 설치 코드에도 들어가지 않는다.
- 미리보기 프레임 메시지 모양은 바꾸지 않는다. 관리자 쪽 연결은 A2-3에서 한다.

### 5.4 스킨 로고 자리

- 넘김 문서(`ads-player-design-handoff.md`) 2절 표를 따른다. 요약:
  - 네 모서리, 여백, 폭(높이는 이미지 비율), 불투명도. 쌓임은 영상 위, 컨트롤·광고 화면 아래.
  - 아래쪽 모서리는 컨트롤이 보이면 컨트롤 막대 위로 올라가고, 숨으면 여백만 남긴다(**제안**, 어려우면 보고).
  - 왼쪽 위에서 제목과 겹치면 제목이 비켜 앉는다(**제안**, 어려우면 보고).
  - `hideDuringAds`(기본 켬): 광고가 시작되면 숨고 본편으로 돌아오면 보인다.
  - `hideWithControls`(기본 끔): 컨트롤이 숨을 때 함께 숨는다. 컨트롤 숨김 상태를 읽는 방법은 구현에서 정하고 보고한다(명세 Q6).
  - 나타나고 사라질 때는 기본 스킨 컨트롤 숨김 전환과 같은 시간과 가속을 쓴다. 움직임 줄이기면 바로 바꾼다.
  - 링크(`href`)가 있으면 `<a target="_blank" rel="noopener noreferrer">`로 감싼다. 이름은 `alt` + 플레이어 화면 언어의 "(새 탭에서 열림)"이다. ko "(새 탭에서 열림)", en "(opens in a new tab)", ja "（新しいタブで開きます）", zh-CN "（在新标签页中打开）". 초점선은 기본 스킨 초점선이고 Tab 순서는 컨트롤보다 앞이다(**제안**).
  - 링크가 없으면 장식 그림(`alt=""`)이고 누름을 받지 않는다. 누르면 영상 쪽 동작(재생·멈춤)이 그대로 일어난다.
  - 이미지를 불러오지 못하면 자리를 숨긴다. 깨진 그림을 보이지 않는다.
- 로고 값만 바뀌면 플레이어를 다시 만들지 않고 고칠 수 있으면 그렇게 한다(`restyle`). 다시 만들어야 하면 이유를 보고한다.
- 폭 상한(넘김 문서 2절 "360" 열린 질문, A2E-02로 결정, 2026-10-22): 그려지는 폭은 `logo.width`와 플레이어 폭의 1/4 중 작은 값이다. 높이는 이미지 비율을 따른다. 저장값과 렌더 값은 그대로 두고 스킨에서만 줄인다. 왼쪽 위 로고 옆 제목의 비켜 앉는 간격도 줄인 폭으로 잰다.

### 5.5 샘플 로고

- 가상의 업체 로고다. 실제 회사나 상표를 닮지 않게 하고, 그림에 "SAMPLE" 같은 표시를 넣어 시험용임을 알 수 있게 한다.
- `public/examples/sample-logo.svg`: 가로형 워드마크. 배경 투명. 글자는 윤곽선(path)으로 바꿔 글꼴에 기대지 않는다. 밝은 장면과 어두운 장면 모두에서 보이게 한다(예: 흰 채움 + 옅은 어두운 테두리).
- `public/examples/sample-logo.png`: 투명 PNG. 정사각형 엠블럼으로 해서 비율이 다른 경우를 시험한다. 반투명 부분을 넣어 알파가 살아 있는지 보이게 한다. 1024px 이하, 512KB 이하(업로드 한도와 같다). 2배 해상도(예: 폭 80 기준이면 160 이상)로 만든다.
- 만든 방법(원본 SVG와 변환 명령)은 디자인 쪽에 남긴다.

### 5.6 데모 "로고" 묶음

- 묶음 순서는 재생 동작 · 표시 · 컨트롤 · 로고 · 언어 · 미디어다.
- 항목: 로고 이미지(없음(기본) · 샘플 SVG · 샘플 PNG(투명), 주소 직접 넣기는 디자인이 정한다), 위치(CornerPicker), 폭(24–240, 기본 80), 불투명도(10–100%, 기본 80), 여백(0–48, 기본 12), 링크 주소, 대체 텍스트(링크가 있으면 필수), 광고 중 숨기기(기본 켬), 컨트롤과 함께 숨기기(기본 끔).
- 이미지가 "없음"이면 나머지 항목은 이유와 함께 막힌다. `native` 프리셋이면 묶음 전체가 이유와 함께 막힌다(컨트롤 묶음과 같은 규칙).
- 값은 지금 데모 상태처럼 주소(query)에 남아 공유할 수 있다.
- 설치 코드에는 로고가 들어가지 않는다. 설치 코드 카드 근처에 한 줄로 알린다(예: 로고는 프리셋 값이고 업로드는 준비 중이라 설치 코드에 넣지 않았다는 뜻. 문구는 디자인).
- 레이아웃 값은 프리셋 값 위에 덮는다. 저장된 프리셋의 로고 값을 바꾸지 않는다.

## 6. 사용자 결정 (2026-10-22)

1. `controls.captions` 기본값 `true`(자막 켜기)는 그대로 둔다.
2. 자막이 없을 때 "자막 없음" 글자는 화면에 보이지 않는다. 컨트롤 막대 안에서만 알린다.
   - 폭 32rem 이상: 지금처럼 비활성 자막 아이콘(`aria-disabled`, 초점은 받음)을 둔다.
   - 모든 폭: 설정 메뉴에 "자막" 항목을 비활성으로 남긴다. 값 자리는 "없음"이고, 열리지 않는다. 32rem 아래에서는 아이콘이 숨으므로 이 항목이 알리는 자리다.
   - 스크린 리더 이름과 마우스를 올릴 때의 툴팁은 "자막 없음"으로 둔다. 다른 아이콘의 툴팁과 같은 규칙이다.
   - 도움말과 데모 문구에서 "자막 없음을 보여요"처럼 글자가 보인다는 뜻의 문장은 고친다.
3. v1에서 영어 광고(`ads.locale: "en"`)로 만든 프리셋은 v2로 읽을 때 직접 넣은 광고 문구(`ads.labels.*`)를 버리고 한국어 기본 문구를 쓴다.
   - 플레이어 화면 언어(`language: "en"`)는 지금처럼 옮긴다.
   - `ads.locale`이 `null`이나 `ko`인 프리셋의 문구는 그대로 둔다. 운영자가 직접 쓴 글자이기 때문이다.
   - 목록 응답에 `migratedLabels`(문구를 바꾼 프리셋 id 목록)를 더한다. 관리자 목록은 이전 안내 옆에 이 사실을 알린다.
4. "업체 로고"는 플레이어를 설치한 홈페이지의 자체 로고다(사이트 홍보용). 지금 만든 플레이어 구석 로고(5절)가 맞으므로 동작은 바꾸지 않는다. 데모와 도움말의 로고 설명에 이 쓰임을 한 줄 더한다.
